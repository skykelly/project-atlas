# I-2. 모델 역량·비용·사용 조건

[주제 목차](README.md) · [시장·기업 경쟁](I-1_market_competition.md) · [변경 이력](LOG.md)

조사 기간 **2026-01-01~2026-10-06**, 현행 가격 확인일 **10-06**. 비교는 공개 문서 검토이며 직접 API 호출·한국 계정 제공·한국어 평가·청구서 검증은 수행하지 않았다.

## 1. 모델 순위보다 업무 완료 조건이 먼저다

모델은 문서를 읽고 도구를 고르며 여러 단계의 과업을 수행한다. 같은 모델도 추론 설정, 입력 길이, 검색·도구, 메모리 구성에 따라 결과와 비용이 달라진다. 모델명은 후보를 좁힐 뿐이다. 안정적인 업무 완료는 별도로 설계해야 한다.

| 선택 축 | 실제로 확인할 것 | 업무 예시 |
|---|---|---|
| 판단·추론 | 여러 조건·예외를 동시에 반영하는지 | 제품 설치 가능성과 추가 비용 설명 |
| 도구 실행 | 올바른 함수·인자·순서를 선택하는지 | 정책 확인 뒤 견적 생성 |
| 문서·멀티모달 | 표·이미지·도면을 근거와 연결하는지 | 설명서 표의 모델별 조건 추출 |
| 지연·동시성 | 첫 응답과 전체 완료시간, p95 | 고객 대화와 야간 일괄 처리 |
| 비용 | 토큰·캐시·도구·재시도·검수 | 한 번 생성이 아닌 수락된 결과당 비용 |
| 이용 조건 | 국가·리전·승인·데이터·라이선스 | 고객정보 처리와 상업 서비스 배포 |

이 표는 선택 기준이다. 업무 예시는 내부 운영 사실을 뜻하지 않는다. 특히 고객이 기다리는 상담과 여러 시간 동안 처리하는 분석에는 다른 시간·품질 요구가 있다.

## 3. 현행 API 가격 — 동일 단위와 제공 단계로 비교

아래는 **USD / 1M tokens**, 일반 텍스트·standard 기준이다. OpenAI는 표의 short context 기준이며 long context·Batch·Fast는 다르다. 클라우드 파트너 가격·기업 할인·세금·환율·이미지/오디오·도구비는 포함하지 않는다.

| 모델 | 입력 | 캐시 읽기 | 출력 | 제공·비교 조건 |
|---|---:|---:|---:|---|
| GPT-6 Luna | $0.10 | $0.01 | $0.50 | 낮은 비용 후보; 업무 품질은 별도 평가 |
| GPT-6.1 Sol | $2 | $0.10 | $10 | API·Work·Codex; 발표상 Chat 미제공 |
| GPT-6 Astra | $10 | $1 | $50 | 어려운 과업 후보; 일반 과업 전량 사용의 경제성 별도 |
| Claude Sonnet 5.5 | $2 | $0.20 | $10 | 범위가 정해진 일상 업무 후보 |
| Claude Opus 5.5 | $4 | $0.20 | $20 | 복잡한 판단·장기 업무 후보 |
| Claude Fable 5.1 | $10 | $0.25 | $50 | GA; Mythos 제한 접근과 구분 |
| Gemini 3.8 Flash | $0.75 | $0.075 | $3.75 | 12-31까지 도입 가격, GA |
| Gemini 4 Argon | $2 예정 | $0.10 예정 | $10 예정 | 단계 제공 모델의 발표 가격, 일반 구매 가능으로 쓰지 않음 |

원문과 추가 비용은 [GPT](evidence/OAI-MODELS-20261006-001.md), [Claude](evidence/ANT-MODELS-20261006-001.md), [Gemini](evidence/GOO-MODELS-20261006-001.md). 이 표만으로 품질 순위나 최저가 서비스를 결정할 수 없다. 입력·출력 단위가 같아도 tokenizer와 추론량이 다르다. 같은 한국어 문장도 토큰 수와 과업 완료비가 달라진다.

### 가격표에서 놓치기 쉬운 조건

- **기간:** Flash는 2027-01-01부터 입력 $1.50·출력 $7.50로 안내한다. 동일 사용량의 기본 토큰비는 도입 가격 대비 2배다.
- **입력 길이:** Sol long context 입력 $4·출력 $15로 별도다. large document 요청을 short 가격으로 계산하지 않는다.
- **캐시:** 읽기 할인만 아니라 처음 쓰기·갱신·보관비가 있다. Gemini는 캐시 저장 시간 비용을 별도 안내한다.
- **검색·도구:** Google Search grounding은 무료 범위 이후 요청당 추가 비용이 있다. API 텍스트 단가가 전체 Agent 비용은 아니다.
- **속도·배포:** Fast·Batch·지역 처리 조건은 별도다. API·앱 구독·managed agent 가격을 동일 상품으로 취급하지 않는다.

## 4. 토큰 단가를 성공 과업당 비용으로 바꿔 계산한다

과업 비용은 각 호출의 입력·캐시 읽기/쓰기·출력 비용에 도구·연산·재시도·사람의 검수 비용을 더한 값이다. 성공 과업당 비용은 그 총비용을 실제 수락된 결과 수로 나눈다. 요청 수와 결과 수가 다르면 요청당 비용만으로 운영 효율을 알 수 없다.

### 4.1 같은 토큰량의 단순 예시

가정: 요청 1건 **새 입력 10,000 tokens + 출력 2,000 tokens**, 캐시·도구·추가 추론 청구·재시도 없음, 표의 standard/short 조건. 동일 품질을 가정하지 않는 산술 예시다.

| 모델 | 입력비 | 출력비 | 1건 합계 | 10,000건 합계 |
|---|---:|---:|---:|---:|
| GPT-6.1 Sol | $0.020 | $0.020 | $0.040 | $400 |
| Claude Opus 5.5 | $0.040 | $0.040 | $0.080 | $800 |
| Gemini 3.8 Flash, 2026 도입 가격 | $0.0075 | $0.0075 | $0.015 | $150 |
| Gemini 3.8 Flash, 2027 안내 가격 | $0.015 | $0.015 | $0.030 | $300 |

2026년 도입 가격으로 2027년 예산을 확정하면 비용을 절반으로 잡게 된다. 실제 Agent는 답변 이전에 추가 추론·도구 실행을 하므로 여기의 출력 2,000보다 청구 토큰이 더 많을 수 있다.

### 4.2 단가가 낮아도 실패가 많으면 비싸진다

가정: A는 요청당 $0.04·수락률 80%, B는 $0.08·수락률 95%. 단순 계산하면 성공 결과당 모델비는 A $0.05, B 약 $0.0842다. 그러나 실패 1건당 사람 보정비가 가정상 $1이라면 1,000건의 총비용은 A $240/800건=$0.30, B $130/950건≈$0.137이 된다.

이 값은 **가상 예시**이며 A·B를 특정 모델에 대응시키지 않는다. 낮은 품질에서 발생하는 검수·실패 비용은 초기 단가 절감을 지워 버린다. 실제 비교 전에 수락 기준, 실패 처리, 작업 난도를 고정해야 한다.

## 5. Benchmark를 업무 성과로 옮길 때 빠지는 조건

| 공개 결과 | 정확한 의미 | 그대로 적용할 수 없는 곳 |
|---|---|---|
| Sol 낮은 effort 오류 답변 11.4%→7.7% | 어려운 오류 유발 대화의 자사 평가, 3.7%p 감소 | 일반 한국어 상담 전체의 오류율 |
| Opus typical workload 40% 비용 감소 | 단가·캐시·작업량을 포함한 자사 비교 | 모든 고객의 전체 AI 운영비 |
| Fable typical 약 25% 비용 감소 | default effort·8월 4주 실사용 기반 비교 | 캐시 적중이 낮은 신규 단발 질문 |
| Argon DeepSWE 77.9%, AutomationBench 51.3% | 서로 다른 장기 코딩·업무 실행 평가 | 두 점수의 평균으로 기업 자동화율 계산 |

[평가 조건](evidence/OAI-MODELS-20261006-001.md) · [Claude 비교](evidence/ANT-MODELS-20261006-001.md) · [Gemini 비교](evidence/GOO-MODELS-20261006-001.md)

예를 들어 설치 정책을 잘 설명하려면 모델이 긴 문서를 읽는 능력뿐 아니라 최신 정책을 검색하고 지역·제품 조건을 구분해야 한다. 코드 benchmark가 높아도 검색 문서가 오래됐거나 권한이 잘못 적용되면 고객 답변은 틀릴 수 있다. 업무 품질은 모델·지식·도구·운영 구성의 결과다.

비교 평가에서는 다음을 함께 기록한다.

1. 모델 ID·버전·접근 경로와 평가일.
2. 동일한 입력·근거·도구 권한·추론 설정.
3. 정답 또는 수락 기준, 모호한 과업의 사람 평가 기준.
4. 실제 청구 토큰·도구 호출·재시도·p50/p95 지연.
5. 반복 실행 변동과 실패 유형, 사람이 수정한 시간.

## 6. 긴 context·멀티모달·open-weight가 주는 선택권

### 6.1 긴 입력과 긴 출력은 다른 기능이다

Gemini 3.8 Flash의 **입력 context 1M·최대 출력 64k**와 Argon의 발표 **최대 출력 1M**은 별개다. 문서를 많이 넣을 수 있다는 것과 여러 단계의 추론·코드를 길게 생성할 수 있다는 것은 서로 다른 요구를 해결한다. [조건](evidence/GOO-MODELS-20261006-001.md)

긴 context도 정보가 최신이거나 모든 근거를 정확히 사용함을 보장하지 않는다. 업무에 맞는 검색·필터링·권한·근거 추적과 비교해야 한다. 제품 매뉴얼 전체를 반복 입력하는 방식은 비용과 변경 관리의 부담도 생긴다.

### 6.2 공개 weights는 무료 상업 서비스와 같지 않다

| 후보 | 공개 특징 | 실제 선택 조건 |
|---|---|---|
| EXAONE 4.5 | 33B vision-language, 한국어·문서 평가 및 serving 안내 | 공개 라이선스는 연구·교육 범위, 상업 조건 별도 확인 |
| Qwen3.6-27B | 공식 weights 공개·Apache 2.0 LICENSE | 선택한 repository·버전의 조건과 자체 운영 책임 확인 |
| 관리형 API | 공급자가 연산·모델 업데이트를 제공 | 과금·데이터·리전·버전 변화 관리 |
| 자체 호스팅 | 데이터·버전·연산 배치 선택권 | GPU·동시성·보안·운영·idle 비용 포함 |

[원문·라이선스·한계](evidence/OPEN-MODELS-20261006-001.md). 공개 EXAONE 조건은 내부의 별도 계약·권리를 판단한 결과가 아니다. 또한 GPU에서 ‘모델을 실행할 수 있다’는 예시는 고객이 동시에 사용할 때 요구하는 응답시간·비용 견적이 아니다.

## 7. 한국 기업의 적용 — 과업을 나눠 평가하는 순서

| 과업 | 후보 구성의 방향 | 판단 지표 |
|---|---|---|
| 분류·추출·짧은 안내 | 낮은 비용·낮은 지연 후보에서 시작 | 필드 정확성·형식 준수·실패 비용 |
| 제품 비교·정책 설명 | 근거 검색과 중간 역량 모델 결합 | 조건 누락·근거 일치·응답 지연 |
| 복잡한 분석·개발 | 고급 모델을 어려운 단계에 사용 | 결과 수락·도구 정확성·재시도 |
| 민감 문서·자체 배포 | 계약·라이선스·권한을 통과한 후보 | 보안·품질·동시성·총운영비 |

표는 시험 설계이며 특정 모델 구매 권고나 내부 도입 실적이 아니다. 모델에 과업을 나누는 방식도 실제 라우팅·전환 시 품질 손실과 개발비가 있으므로 전량 하나의 모델을 사용하는 기준 구성과 비교한다.

1. 한국어 과업·동일 근거를 준비하고 입력 데이터의 개인정보·접근 조건을 확인한다.
2. 사용할 수 있는 후보만 골라 동일한 수락 기준으로 시험한다. 제한 접근 모델을 운영 후보의 비용 절감 근거로 넣지 않는다.
3. 단발 답변과 반복 과업을 나눠 캐시·추론·실패·검수까지 기록한다.
4. 모델·가격·API 변경 시 같은 과업을 재평가한다. 낮은 단가보다 안정적인 성공 결과당 비용을 판단 기준으로 삼는다.

## 8. 실행 판단

- **2026년에는 능력·속도·작업당 비용·접근 조건을 함께 비교한다.** 공급자 평가는 실제 고객 환경에서 다시 측정한다.
- **정적인 가격표를 예산으로 쓰지 않는다.** 기간 한정 가격·캐시·추론·도구·사람 보정이 총액을 바꾼다.
- **입력 길이·출력 길이·메모리를 분리한다.** 긴 context는 지식 갱신과 권한 문제를 해결하지 못한다.
- **배포 선택권만큼 운영 책임도 커진다.** 공개 weights를 택하면 라이선스·연산·보안·운영을 기업이 떠안는다.
