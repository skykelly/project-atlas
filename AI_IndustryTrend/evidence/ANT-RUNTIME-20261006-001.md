## 확인한 내용과 측정 조건

- harness·sandbox·세션 로그를 분리한다. durable event log로 harness 재시작을 지원하고, sandbox 장애는 도구 오류로 처리해 재생성할 수 있다. OAuth 자격증명은 별도 vault/proxy에서 처리한다.
- 내부 구조 변경 뒤 첫 토큰 지연 TTFT의 p50 약 60%, p95 90% 이상 감소를 보고했다. 전체 과업 완료시간이나 타사 대비 수치가 아니다.
- 현행 제품은 beta, `managed-agents-2026-04-01` header 필요, API 계정 기본 접근. MCP tunnels·dreaming은 별도 제한 research preview다.
- 세션·파일·결과를 서버에 보관하며 현재 ZDR·HIPAA BAA 대상이 아니다. 세션과 업로드 파일의 삭제는 별도다.

## 검증 수준·한계

지연 수치는 기업 내부 변경 전후 보고이며 표본·절대 지연·독립 재현은 공개되지 않았다. 이벤트 로그 복구와 외부 결제·메일 등의 중복 방지는 다른 문제다. beta 기능·데이터 조건을 모델 API 전체와 혼동하지 않는다.
