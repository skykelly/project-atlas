## 확인한 내용과 측정 조건

- 세션은 한 상호작용의 history·framework state, 메모리는 이후 다른 대화에도 필요한 사실·선호·결정이다. 모두 Lakebase 저장 기반이며 세션 삭제가 메모리 삭제로 이어지지 않는다.
- 현행 managed memory는 Beta. preview 동안 memory 자체 추가 요금 없이 underlying Lakebase instance 과금, 변경 가능하다.
- entry는 actor_id·선택 session_id·path로 조직한다. 검증된 사용자 identity에서 actor_id를 애플리케이션이 정하도록 안내하며 모델이 대상 사용자를 선택하면 안 된다.
- overview는 semantic search라는 표현을 쓰지만 상세 retrieval은 full-text BM25 ranking을 명시한다. 이 문서만으로 vector 검색 구현을 단정하지 않는다.

## 검증 수준·한계

이전 UC-governed memory는 legacy로 표시된다. 해당 권한 모델을 새 Lakebase memory에 그대로 적용했다고 쓰지 않는다. 기억 자동 생성·정확성 개선·법정 삭제의 완결성은 별도 실험·운영 절차가 필요하다.

`reviewed`는 2026-10-06 원문 확인이다. 독립 재현·계약·계정 제공·내부 데이터 적용 검증은 수행하지 않았다.
