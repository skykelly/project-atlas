## 확인한 내용과 조건

- Trn3는 2025년 12월 GA로 2026 사용 선택지의 배경이다. 현행 최대 144 Trainium3 chips·362 FP8 PFLOPs, Trn2 대비 performance 최대 4.4배·performance/watt 4배라는 공급자 비교.
- Neuron stack·PyTorch/JAX 및 hosting services 통합을 설명한다. 높은 peak는 개별 모델 전체 비용 절감률이 아니다.
- 9월 OpenAI 발표에서 연결한 Bedrock Managed Agents는 현행 Preview. OpenAI model·Codex harness·AgentCore, runtime/inference AWS 내부와 AWS identity를 설명한다.
- managed Agent 상품과 직접 accelerator를 운영하는 EC2 선택은 관리 책임이 다르다.

## 검증 수준·한계

2025년 GA를 2026 신제품 출시로 쓰지 않는다. 가격·리전·capacity·API 계약은 제품별 확인 대상이며 AWS 내부 실행을 모든 enterprise 설정의 무조건적 data isolation 보장으로 확장하지 않는다. 모델 API 가격과 chip 성능 비교를 혼합하지 않는다.
