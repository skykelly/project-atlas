## 확인한 내용과 측정 조건

- 4월 SDK 발표는 sandbox·Manifest·checkpoint 복구를 포함하며 GA, Python부터 출시한다고 명시했다. 당시 TypeScript 계획을 현재 완료 사실로 쓰지 않는다.
- 현행 SDK는 고객 애플리케이션이 배포·도구·상태 저장·승인 결정을 맡는다. Agents API는 OpenAI가 Codex harness·세션·압축·복구를 관리한다. SDK와 managed API의 운영 책임이 다르다.
- Agents API 예제는 beta endpoint/header를 사용한다. 현행 안내상 데이터 residency는 미국만, ZDR은 미지원이며 self-hosted sandbox 선택도 이를 바꾸지 않는다.
- Computer use 문서는 브라우저 origin·인증 요청을 required actions로 처리한다. 승인 응답 HTTP 202는 결정 접수이지 탐색 완료가 아니다.

## 검증 수준·한계

출시 글과 현행 문서의 시점을 구분했다. SDK GA를 Agents API GA로 전이하지 않는다. 컴퓨터 사용의 한국 계정·개별 사이트 성공률·데이터 계약은 검증하지 않았다. 기능 제공은 무인 업무 완결률이나 외부 쓰기 exactly-once 보장이 아니다.
