# Genie One MCP — 외부 Agent의 기업 분석 경로

[주제 목차](../README.md)

## 제공 조건

Genie를 외부 Agent가 질문·진행 조회·query 결과로 호출한다. MCP Apps 지원 client는 시각화와 근거를 표시한다. 이는 Genie Ontology 전체의 GA 전환을 뜻하지 않는다.

Unity Gateway의 MCP Service `system.ai.genie_one_mcp`는 UC grants·tool 정책·호출 감사를 적용한다. 사용자 대리 OAuth를 권고하며 service principal도 지원한다. 기본 응답은 결과를 자를 수 있고 전체 결과 조회에도 크기 제한이 있다. 이전 Beta `/api/2.0/mcp/genie`는 2026-10-31 종료 예정이며 새 endpoint와 OAuth scope를 사용하도록 안내한다.

## 한계

GetYourGuide 발언은 여러 화면에서의 공통 분석 경로에 관한 고객 인용이며 정량 ROI·독립 비교가 없다. 업무 쓰기·전체 Agent 결과 일치·한국 계정·리전·비용·권한 회수를 직접 시험하지 않았다. 가격은 Genie 사용 조건을 따르며 무료 MCP라는 의미로 쓰지 않는다.
