## 확인한 내용과 측정 조건

- Web·개인 가시성 Slack은 요청자 권한을 사용한다. 채널 전체 가시 응답은 broad-access corpus를 사용하며 각 채널 구성원의 모든 문서 권한을 일일이 검사하는 방식은 아니다.
- Company knowledge profile은 관리자가 connector·workspace·group 등의 범위를 정한다. auto-agent의 User data와 Public data는 검색 정체성과 공유 범위가 다르다.
- 공유 실행에서 개인 private credentials를 써서 자료를 찾는 경로를 제한한다. 승인된 corpus는 원 애플리케이션의 모든 개인에게 직접 접근을 주는 것과 다르다.
- agent 공유 패널의 API token은 해당 Agent에만 scoped, 1년 만료, 회전은 삭제 후 재생성한다.

## 검증 수준·한계

Public은 인터넷 공개를 뜻하지 않는다. Agent 실행 권한과 자료 조회·응답 공개 권한도 별개다. 실제 connector별 인덱싱·권한 회수 지연·shared response 누출 시험은 하지 않았다. 2026년 현행 문서이며 각 기능의 최초 출시일을 뜻하지 않는다.
