## 확인한 내용과 측정 조건

- 3월 stateful MCP 서버는 elicitation·sampling·progress notifications와 사용자별 microVM·session ID를 지원한다. 발표의 14개 리전에는 서울이 포함된다.
- 8월 runtime instances는 EC2 기반 관리 compute로 GPU·동일 호스트 협업·stop/restart, 세션 최대 14일을 설명한다. 기존 runtime microVM invocation 최대 8시간과 다른 compute 옵션이다.
- instances 발표 리전은 미국 3·아시아 4·유럽 2개이며 서울은 열거되지 않는다. 과금은 EC2 가격에 orchestration 관리 수수료를 더하는 방식이다.

## 검증 수준·한계

발표된 기능별 리전을 구분했다. MCP 지원 14리전으로 instances의 서울 지원을 추론하지 않는다. 14일은 세션 지속 조건이며 단일 작업 성공·SLA·무인 연속 실행 보장이 아니다. 실제 AWS 계정 배포·청구는 수행하지 않았다.
