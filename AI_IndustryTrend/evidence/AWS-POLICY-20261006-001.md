## 확인한 내용과 조건

- Policy 03-03 GA. 자연어 규칙을 Cedar로 바꾸거나 직접 작성해 policy engine에 저장하고 Gateway에 연결한다. 모델 코드 밖에서 tool 접근·입력을 allow/deny한다.
- Cedar는 default deny, forbid가 permit보다 우선, 순서 독립 평가다. 자연어 생성 후 schema 검증·과도한 허용/제한 분석을 설명한다.
- GA 발표 13리전에 서울이 포함된다. 이는 해당 날짜·해당 기능의 목록이며 Evaluations·Runtime instances에 그대로 적용하지 않는다.
- 적용 범위는 AgentCore Gateway를 통과하는 호출이다. 별도 network·직접 API·local shell 경로까지 자동 통제한다는 주장은 하지 않는다.
