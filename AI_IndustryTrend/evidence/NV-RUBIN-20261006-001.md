## 확인한 내용과 조건

- 1월 Rubin은 CPU·GPU·switch·NIC·DPU·Ethernet을 함께 설계하는 platform으로 발표했다. Blackwell 대비 MoE inference token cost 최대 10배 낮음·training GPU 4배 적음이라는 공급자 비교다.
- 5월 full production ramp 발표는 5개 purpose-built rack의 POD 구성과 Grace Blackwell 대비 agent throughput 10배를 제시한다.
- token cost·GPU 수·agent throughput은 서로 다른 지표이며 고객 API 가격이나 모든 모델의 속도와 동일하지 않다.
