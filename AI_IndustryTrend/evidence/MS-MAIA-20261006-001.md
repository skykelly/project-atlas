- inference accelerator: 3nm·216GB HBM3e·7TB/s·272MB SRAM, FP4 10+PFLOPS·FP8 5+PFLOPS·750W SoC TDP라고 발표했다.
- Microsoft 당시 최신 fleet hardware 대비 performance/dollar 30% 개선. 독립 타사 rack 비교나 API 단가 30% 인하가 아니다.
