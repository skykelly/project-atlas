## 확인한 내용과 측정 조건

- Opus 4.6 16개 Agent, 약 2주·거의 2,000 Claude Code 세션. 입력 20억·출력 1억4,000만 tokens, API 비용 약 2만 달러 미만으로 보고했다.
- 약 10만 줄 Rust C compiler가 Linux 6.9의 x86·ARM·RISC-V 빌드를 수행했다고 발표했다. 개발 중 인터넷 접근 없는 clean-room 실험이다.
- 대부분 compiler test suite에서 99% 통과라는 보고는 해당 시험 범위다. Linux real-mode 부트용 16-bit x86은 GCC 의존, 데모 assembler/linker도 GCC 사용, 최적화 효율·전문가 수준 코드 품질에 한계가 있다.

## 검증 수준·한계

기업 연구자의 단일 실험이며 독립 재현하지 않았다. API 비용에는 인간의 harness·시험 설계 노동과 전체 인프라 원가가 포함되었다고 확인할 수 없다. 줄 수·시험 통과율을 업무 생산성·상용 compiler 대체·Agent 16배 가속으로 환산하지 않는다.
