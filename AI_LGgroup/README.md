# LG Group AI — 산업 자산에서 실행·사업화까지

[Atlas 안내](../README.md) · [변경·조사 이력](LOG.md)

**기준일: 2026-10-06. 조사 기간: 2026-01-01~2026-10-06.** 기존 LG 전략 저장소의 여섯 테마를 유지하고, 공식 원문을 다시 확인해 Atlas의 사례·종합 구조로 정리했다. 표·불렛·실행 순서와 맥락 설명을 함께 사용한다.

LG의 AI를 한 개 모델이나 계열사로 설명하기는 어렵다. 인프라 공급, 제조·로봇 실행, 차량 기술, 기업 AX, 과학 연구가 서로 다른 사업·검증 단계를 가진다. 공통 자산은 제조 경험·산업 데이터·부품·설비·전문 지식이며, 외부 플랫폼과 결합하는 방식은 여섯 번째 테마에서 비교한다.

## 심층 조사 리포트 진행

L-1~L-4를 사업 구조·고객 프로젝트·작업 흐름·수치 조건 중심의 심층 리포트로 재작성했다. L-3은 실제 SDV 공급과 AI 경험·배터리 SW, L-4는 종근당 보고서 자동화·품질 데이터·시스템 개발과 AX 공급 사업을 다룬다. L-5·L-6은 기존 종합이며 동일한 깊이의 보완을 순차 진행한다.

## 2. 그룹을 관통하는 비교

| 테마 | 현재 공개 근거의 중심 | 사업 성과와 구분할 것 |
|---|---|---|
| L-1 | 냉각 공급 본계약·제품 자격·전력 확보·모듈 출시 | 수주/매출, IT 부하/수전/열 용량 |
| L-2 | 기존 공장 성과·외부 수주·플랫폼·PoC·데이터 수집 | 기존 자동화/새 로봇의 효과, 기대/실측 |
| L-3 | 차량 AI 시연·부품 제안·SDV 양산·차종 특정 공급 | 통신·콕핏 공급/생성형 AI 전체 상용화 |
| L-4 | 교육·도입·외부 고객·품질 PoC 본사업·개발 적용 | 사용 가능/실제 활성 사용, 목표/실현 ROI |
| L-5 | 후보 탐색·소재 사례·배터리 설계·신약 공동개발 | 계산 탐색/합성·임상·허가·매출 |
| L-6 | 플랫폼·공급·연구·투자 협력 | 협약·자격/발주·거래 완료·매출 |

**조사 해석:** LG는 자체 모델을 만드는 동시에 외부 플랫폼을 이용하고 산업 인프라를 공급한다. 그 전략의 가치가 입증되는 지점은 모델 이름보다 고객 계약, 실제 현장 성능, 연구 검증과 반복 가능한 운영이다. 공개 자료로 확인되지 않은 전사 ROI·독점성·계약 총액은 추정하지 않았다.

## 3. 범위와 읽는 기준

- 최신 내용에는 10월 6일 AIR 냉각 공급·Renault 콕핏 공급, 10월 1일 공동투자 협약, 9월 Microsoft 협력·DSX Ready·전문가 AI를 포함한다.
- 2025년 자료는 2026년 CES 기술의 사전 설명 등 필요한 배경에 한정해 날짜를 표시한다. 2026년 공식 인터뷰가 소개한 과거 공장 성과도 신규 성과로 쓰지 않는다.
- `source_verified`는 원문을 읽고 근거를 연결했다는 뜻이다. 독립 실측·임상 재현·감사는 수행하지 않았다.
- 목표·예상·시연·PoC·계약·납품을 각 사례에서 구분한다. 미공개 조건은 빈칸을 채우는 대신 그대로 남긴다.
- AI Factory는 독립 테마로 만들지 않는다. 연산·전력·냉각은 L-1, 제조 데이터·시뮬레이션·로봇 학습은 L-2에서 관리한다.
- LG와 협업한 LX판토스·GS칼텍스·D&D 등은 외부 협력사로 표시한다.
