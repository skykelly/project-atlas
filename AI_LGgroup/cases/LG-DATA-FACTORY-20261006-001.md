## 확인한 사실과 수치

| 항목 | 원문 확인 내용 | 측정·해석 조건 |
|---|---|---|
| 공간 | 양재 4개 층·연면적 1만㎡ 조성 | 가정·테네시 세탁기 공정 모사·물류·로봇 손 학습 공간 |
| 데이터 목표 | 2026년 말까지 학습 데이터 총 10만 시간 예상 | 직접 수집과 증강·합성 데이터 합계; 모두 실제 로봇 운전 시간이 아님 |
| 로봇 목표 | 연내 투입 수백대·풀가동 목표 | 현 시점 완료 대수 미공개 |

주요 주장은 위 공식 원문과 명시된 근거 위치에 연결된다. 추가 근거가 있는 행은 아래 후속 원문에 연결한다.

## 한계와 미확인

약 12년은 데이터 시간의 비유이며 12년 현장 운전 경험이 아니다. 제조 공정 모사와 실제 공장 상용 배치를 구분한다. 작업 성공률·데이터 다양성·안전 검증값은 미공개.

## 사례 해석

제조·물류 노하우를 물리적 학습 데이터로 전환하는 기반이다. Cosmos·Isaac·Omniverse를 연결하지만 실제 현장으로 옮겼을 때의 성능은 별도 검증 대상이다.
