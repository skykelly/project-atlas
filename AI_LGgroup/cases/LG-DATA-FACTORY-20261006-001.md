- **발표/사건일:** 2026-08-18 (아래 날짜 조건 참조)
- **단계:** 로봇 데이터 수집 중·시설 확장 목표
- **검증 수준:** 공식 원문 확인. 회사 발표와 독립 실측 검증은 구분하며, 독립 재현은 수행하지 않았다.
- **원문:** [양재 로봇 데이터팩토리와 NVIDIA 학습 체계](https://www.lge.co.kr/story/newsroom/236153)
- **근거 위치:** 데이터팩토리 가동 현황 / 제조 데이터 / 규모 문단
- **확인일:** 2026-10-06

## 확인한 사실과 수치

| 항목 | 원문 확인 내용 | 측정·해석 조건 |
|---|---|---|
| 공간 | 양재 4개 층·연면적 1만㎡ 조성 | 가정·테네시 세탁기 공정 모사·물류·로봇 손 학습 공간 |
| 데이터 목표 | 2026년 말까지 학습 데이터 총 10만 시간 예상 | 직접 수집과 증강·합성 데이터 합계; 모두 실제 로봇 운전 시간이 아님 |
| 로봇 목표 | 연내 투입 수백대·풀가동 목표 | 현 시점 완료 대수 미공개 |

주요 주장은 위 공식 원문과 명시된 근거 위치에 연결된다. 추가 근거가 있는 행은 아래 후속 원문에 연결한다.

## 한계와 미확인

약 12년은 데이터 시간의 비유이며 12년 현장 운전 경험이 아니다. 제조 공정 모사와 실제 공장 상용 배치를 구분한다. 작업 성공률·데이터 다양성·안전 검증값은 미공개.

## 사례 해석

제조·물류 노하우를 물리적 학습 데이터로 전환하는 기반이다. Cosmos·Isaac·Omniverse를 연결하지만 실제 현장으로 옮겼을 때의 성능은 별도 검증 대상이다.

## 심층 조사 보완 — 공간별 실제 작업과 데이터 경로

- **추가 원문:** [LG 영문 발표, 게시 2026-08-19 / 본문 2026-08-18](https://lgcorp.com/media/release/30469). 확인일 2026-10-06. 근거 위치: Data Factory 현황·학습 공간·data flywheel·규모 문단.
- CLOiD가 가정 환경에서 청소를 반복하고, 테네시 세탁기 공장 모사 공간에서 부품 이동·적재·조립을 학습한다. CNS 물류와 이노텍 로봇 손 학습 공간도 설명했다. 실제 테네시 생산 라인의 상용 투입을 확인한 내용은 아니다.
- Omniverse·Cosmos·Isaac으로 실제 데이터를 재현·증강·합성하고 RFM 개선에 활용한다. 현장 수집→확장→학습→재수집의 반복이 회사가 설명하는 data flywheel이다.
- 일부 로봇 배치·수집과 시설의 연말 풀가동 목표를 분리한다. 수백대·10만 시간은 연말 목표, 실제·합성 데이터 비중과 작업별 성공률은 미공개다.
