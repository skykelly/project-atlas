# MAP 협력의 컴퓨팅·제조·모빌리티 연결

[테마 종합](../docs/06_global_ai_alliance_open_innovation.md) · [목차](../README.md)

- **발표/사건일:** 2026-06-07 (아래 날짜 조건 참조)
- **단계:** 협력 발표·통합 워크플로 계획
- **검증 수준:** 공식 원문 확인. 회사 발표와 독립 실측 검증은 구분하며, 독립 재현은 수행하지 않았다.
- **원문:** [MAP 협력의 컴퓨팅·제조·모빌리티 연결](https://blogs.nvidia.com/blog/nvidia-and-lg-group-ai-factory/)
- **근거 위치:** Physical AI / DSX Infrastructure / Mobility / EXAONE
- **확인일:** 2026-10-06

## 확인한 사실과 수치

| 항목 | 원문 확인 내용 | 측정·해석 조건 |
|---|---|---|
| 연결 | 모델 개발→물리 데이터→시뮬레이션·학습→엣지 배포·디지털트윈 연결 | 그룹 전 사업 통합 운영 완료가 아님 |
| 기술 축 | Isaac·Cosmos / DSX / DRIVE / EXAONE 개발·추론 도구 | 회사별 적용·탐색·계획을 구분 |

주요 주장은 위 공식 원문과 명시된 근거 위치에 연결된다. 추가 근거가 있는 행은 아래 후속 원문에 연결한다.

## 한계와 미확인

6월 7일 NVIDIA 게시와 한국의 6월 8일 발표 시차를 구분한다. 1만 GPU 도입설은 이 원문에 없어 확정 규모에서 제외한다. 총 투자·독점성·IP 귀속은 미공개.

## 사례 해석

LG의 제조·센싱·냉각·배터리 자산에 외부 컴퓨팅과 개발 도구를 연결한다. GPU 인프라는 L-1, 로봇 데이터·훈련은 L-2에서 각각 사업 근거를 확인한다.
