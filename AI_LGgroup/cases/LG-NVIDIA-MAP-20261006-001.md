# MAP 협력의 컴퓨팅·제조·모빌리티 연결

[테마 종합](../docs/06_global_ai_alliance_open_innovation.md) · [목차](../README.md)

- **발표/사건일:** 2026-06-07 (아래 날짜 조건 참조)
- **단계:** 협력 발표·통합 워크플로 계획
- **검증 수준:** 공식 원문 확인. 회사 발표와 독립 실측 검증은 구분하며, 독립 재현은 수행하지 않았다.
- **원문:** [MAP 협력의 컴퓨팅·제조·모빌리티 연결](https://blogs.nvidia.com/blog/nvidia-and-lg-group-ai-factory/)
- **근거 위치:** Physical AI / DSX Infrastructure / Mobility / EXAONE
- **확인일:** 2026-10-06

## 확인한 사실과 수치

| 항목 | 원문 확인 내용 | 측정·해석 조건 |
|---|---|---|
| 연결 | 모델 개발→물리 데이터→시뮬레이션·학습→엣지 배포·디지털트윈 연결 | 그룹 전 사업 통합 운영 완료가 아님 |
| 기술 축 | Isaac·Cosmos / DSX / DRIVE / EXAONE 개발·추론 도구 | 회사별 적용·탐색·계획을 구분 |

주요 주장은 위 공식 원문과 명시된 근거 위치에 연결된다. 추가 근거가 있는 행은 아래 후속 원문에 연결한다.

## 한계와 미확인

6월 7일 NVIDIA 게시와 한국의 6월 8일 발표 시차를 구분한다. 1만 GPU 도입설은 이 원문에 없어 확정 규모에서 제외한다. 총 투자·독점성·IP 귀속은 미공개.

## 사례 해석

LG의 제조·센싱·냉각·배터리 자산에 외부 컴퓨팅과 개발 도구를 연결한다. GPU 인프라는 L-1, 로봇 데이터·훈련은 L-2에서 각각 사업 근거를 확인한다.

## 심층 조사 보완 — 기술별 적용 상태

기존 NVIDIA 원문의 각 기술 절을 2026-10-06 재확인했다. ‘MAP’은 기존 사례 명칭을 유지한 것이며 원문 전체의 별도 단일 계약명·금액을 확인한 것은 아니다.

| 근거 위치 | 확인 내용 | 상태·한계 |
|---|---|---|
| Physical AI and Robotics | Isaac Sim/Lab, Cosmos; CNS PhysicalWorks 연결 | 로봇 학습·합성 데이터 도구; 현장 작업 성과 수치 아님 |
| 같은 절 | GR00T 활용 탐색·레퍼런스 로봇 공동개발 계획 | 제품 출시·완성 모델 성능 아님 |
| DSX Infrastructure | 냉각·프리패브 기술 협력; CNS/유플러스 시설 계획 | 800V DC 전력 협력 계획과 현재 AC 제품 자격 구분 |
| Mobility | DRIVE Hyperion 정합·DRIVE AGX 활용 계획 | OEM·차종·양산 계약 미공개 |
| Sovereign AI With EXAONE | Blackwell·NeMo·Nemotron 데이터·TensorRT-LLM 활용 | 원문은 실제 개발 활용 설명; 독점·소유권 조건 아님 |

후속 결과는 원문을 복제하지 않고 [양재 데이터 수집](LG-DATA-FACTORY-20261006-001.md), [2.6MW CDU 자격](LG-CDU-DSX-20261006-001.md), [BESS](LG-ESS-DSX-20261006-001.md)에서 재사용한다. 후속 제품 자격이 모두 하나의 계약으로 묶였다고 단정하지 않았다.
