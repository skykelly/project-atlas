# DevOn Agentic AIND의 기업 시스템 개발

[테마 종합](../docs/04_enterprise_ax_agentic_operating_model.md) · [목차](../README.md)

- **발표/사건일:** 2026-06-08 (아래 날짜 조건 참조)
- **단계:** 제품 출시·금융 프로젝트 적용 중
- **검증 수준:** 공식 원문 확인. 회사 발표와 독립 실측 검증은 구분하며, 독립 재현은 수행하지 않았다.
- **원문:** [DevOn Agentic AIND의 기업 시스템 개발](https://www.lg.co.kr/media/release/30232)
- **근거 위치:** Knowledge Foundation / Spec-Driven Development / COBOL to Java
- **확인일:** 2026-10-06

## 확인한 사실과 수치

| 항목 | 원문 확인 내용 | 측정·해석 조건 |
|---|---|---|
| 역할 | 요구 분석·설계·코딩·테스트 에이전트 협업 | 개발 표준·보안 규정·기존 소스를 구조화한 지식 기반 |
| 현장 | 국내 대형 금융사 차세대 프로젝트에 COBOL→Java 기능 적용 중 발표 | 고객명·완료 범위 미공개 |

주요 주장은 위 공식 원문과 명시된 근거 위치에 연결된다. 추가 근거가 있는 행은 아래 후속 원문에 연결한다.

## 한계와 미확인

수주 단위 코드 분석·변환을 분 단위로 단축한다는 설명은 특정 작업 범위의 주장이다. 전체 프로젝트 일정·운영 결함·비용 절감 실측으로 읽지 않는다.

## 사례 해석

생성 코드를 기존 시스템의 규칙 안에 넣는 접근이다. Agent가 초안을 만들더라도 결과 검토·승인과 회귀 검증이 실제 운영 품질을 결정한다.
