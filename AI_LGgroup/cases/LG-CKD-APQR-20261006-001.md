# 종근당 APQR 보고서의 AgenticWorks 자동화

[테마 종합](../docs/04_enterprise_ax_agentic_operating_model.md) · [목차](../README.md)

- **발표일:** 2026-01-21. 구축 완료는 발표 시점까지의 사실이며 정확한 가동 개시일은 미공개.
- **원문:** [LG CNS 제약·바이오 AX 발표](https://www.lg.co.kr/media/release/29787).
- **확인일·위치:** 2026-10-06; 종근당 APQR 섹션.
- **단계·검증:** 공급사 발표상 구축 완료·업무 효과. 고객의 별도 실측·감사는 미확인.

## 확인한 업무와 성과

| 항목 | 공개 내용 | 조건 |
|---|---|---|
| 대상 | 연간 제품 품질평가 보고서 APQR | 품질 보고 업무; 신약 임상 성과 아님 |
| 구조 | AgenticWorks 기반 약 30개 Agent | 자료 수집·분석·검증·작성 협업 |
| 연결 | QMS·LIMS 등 | 품질·실험실 시스템 자료 활용 |
| 효과 | 문서 생성 시간 90% 이상 단축 | 절대 시간·표본·기간·최종 승인 시간 미공개 |

## 해석·한계

사람은 최종 검증에 집중하는 방향이다. 여러 시스템의 업무 자료를 보고서 공정으로 연결한 사례로, 범용 답변보다 데이터 통합·산업 규칙이 중요하다. 생성 시간 감소를 규제 승인·전사 생산성·인건비 절감으로 환산하지 않는다. 같은 원문의 정부 신약개발 과제 371억원은 이 고객 계약액이 아니다.
