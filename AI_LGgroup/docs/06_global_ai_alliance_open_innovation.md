# L-6. Global AI Alliance / Open Innovation

[LG Group 목차](../README.md) · [조사 이력](../LOG.md)

**조사 기간: 2026-01-01~2026-10-06.** 발표일·수치 조건·계약 단계는 연결된 사례에 기록했다. 아래 사업 전망은 공개 사실에서 도출한 해석이다.

## 1. LG는 플랫폼을 쓰고 제품·서비스를 공급한다

LG는 NVIDIA·Microsoft의 기술을 쓰고 냉각·전력·센서·제조 데이터를 공급한다. CNS는 기업 고객의 AI 도입·운영을 맡는다. 10월에는 General Atlantic과 SW IP·고객 기반을 확보할 공동투자 협약을 체결했다. 플랫폼 이용, 산업 제품 공급, 실행 서비스, 자산 투자가 각각의 계약으로 움직인다.

| 협력 유형 | LG의 위치 | 구체적인 근거 | 사업 결과로 확인한 범위 |
|---|---|---|---|
| 기술·제품 생태계 | 개발자·장비/부품 공급자 | NVIDIA 도구·DSX·DRIVE 협력 | 제품 자격과 일부 데이터 수집; 통합 가동 완료 아님 |
| 글로벌 수요 연결 | 잠재 공급자·플랫폼 이용자 | Microsoft 3개 협력 축 | 전략 합의·공급 기회·전환 계획 |
| 구매·공급 관계 | 장비 제조사 | AIR 장기 칠러 계약 | 본계약; 납품·매출 일정은 별도 |
| 기업 AI 실행 채널 | 도입·통합·운영 사업자 | OpenAI·Anthropic·Palantir | 고객 확보·사용 제공·품질 본사업 계약 |
| 과학 공동개발·딜리버리 | 모델 개발자 또는 플랫폼 실행자 | D&D·GS칼텍스·CuspAI | 역할 분담·소재 개발·도입 지원 계획 |
| 투자·자산 확보 | SW·AI 사업 확장 주체 | General Atlantic | 공동투자 협약; 거래 완료 아님 |

DSX 자격은 제품 적합성을, AIR 본계약은 공급 관계를 확인한다. 직원 사용 제공은 도입 범위다. 투자 협약은 기업 발굴의 출발점이다. 각 지표가 거래·매출로 이어지는 시점은 아래 사례별로 다르다.

## 2. NVIDIA: 로봇 훈련·시설 규격·차량 개발 도구

### 2.1 각 기술을 쓰는 조직과 현재 단계

6월 7일 NVIDIA는 LG와 학습·시뮬레이션·검증·배포를 연결하는 AI Factory 협력을 발표했다. 로봇 훈련, 시설 설계, 차량 플랫폼, EXAONE 개발에 서로 다른 도구를 제공한다.

| 영역 | 외부 기술의 기능 | LG 측 기여·사업 접점 | 상태 |
|---|---|---|---|
| 로봇 학습 | Isaac Sim/Lab의 시뮬레이션·훈련, Cosmos의 합성 데이터 | 전자 제조 경험·로봇 데이터, CNS PhysicalWorks | 도구 연결·데이터 기반 확대 |
| 로봇 모델 | Isaac GR00T의 로봇 기반 모델 | 가정 로봇·모듈형 로봇 개발 | 활용 탐색·레퍼런스 로봇 공동개발 계획 |
| AI 인프라 | DSX의 시설 참조 구조 | 전자 냉각·모듈 설계, 에너지솔루션 전력, 유플러스/CNS 시설 | 자격·구축 계획을 개별 사례로 확인 |
| 차량 | DRIVE Hyperion의 센서·컴퓨팅·SW 정합, DRIVE AGX | 전자 ADAS·차량 AI, 이노텍 부품 | 기술 로드맵·협력 계획 |
| EXAONE | Blackwell·NeMo·Nemotron 데이터·TensorRT-LLM | AI연구원 모델 개발·추론 엔진 | 원문은 실제 개발 활용을 설명 |

출처: [NVIDIA 협력 사례](../cases/LG-NVIDIA-MAP-20261006-001.md). DRIVE 정합 계획의 OEM·양산 차종은 미공개다. EXAONE 개발 도구 활용에 관한 발표는 모델 소유권 조건을 제시하지 않는다.

### 2.2 데이터 수집과 CDU 자격까지 진행했다

| 날짜 | 별도 사례에서 확인한 변화 | 6월 협력과의 연결 | 여전히 구분할 것 |
|---|---|---|---|
| 6월 7일 | 그룹 차원의 기술 협력 방향 | 모델·데이터·시뮬레이션·시설 연결 | 총 투자·GPU 확정 수량 미공개 |
| 8월 18일 | 양재 4개 층·약 1만㎡ 데이터팩토리, 일부 로봇 데이터 수집 | 실제 작업 데이터와 합성·증강의 학습 경로 | 연말 10만 시간·수백대는 목표 |
| 9월 22일 | 2.6MW CDU의 DSX Ready 요건 충족 | 기술 생태계의 제품 적합성으로 구체화 | 구매 보장·납품액 아님 |

근거: [데이터팩토리](../cases/LG-DATA-FACTORY-20261006-001.md), [CDU](../cases/LG-CDU-DSX-20261006-001.md). 학습 시간에는 합성·증강 데이터가 포함된다. 6월 협약과 각 후속 계약을 하나의 법적 계약으로 묶을 근거는 공개하지 않았다.

LG는 제조 현장에서 학습 데이터를 확보하고 냉각·전력 제품을 개발한다. NVIDIA는 개발 도구와 시설 참조 구조를 제공한다. 데이터 수집과 제품 자격은 각각 후속 작업까지 진행했다. 공식 협력 원문에는 GPU 1만대 확정 도입 내용이 없다.

## 3. Microsoft: 설비 공급 기회와 플랫폼 도입 계획

9월 21일 미국 Redmond에서 LG와 Microsoft 경영진은 AIDC·기업 AX·Physical AI 협력을 논의했다. LG는 설비 공급 기회를 찾고 업무 환경 전환과 모델 학습을 추진한다. 각 축의 현재 단계는 다음과 같다.

| 축 | 단기·중기 내용 | LG의 거래상 위치 | 확인 수준 |
|---|---|---|---|
| AIDC | 전략 지역의 대용량 냉각 공급 기회, 중장기 프리패브 시설 | Microsoft 확장의 잠재 공급자 | 특정 센터 발주·공급액 미공개 |
| 기업 AX | Microsoft 365 E7·Copilot 등 AI/클라우드로 글로벌 지식근로 환경 전환 | 업무 플랫폼 이용자 | 전체 지식근로자 대상 계획; 배포 완료 아님 |
| Physical AI | 제조·물류·모빌리티 모델 학습과 데이터 수집의 반복 | 클라우드 이용자·현장 데이터 기여자 | Data Flywheel 추진; 작업 성공률 미공개 |

근거: [Microsoft 사례](../cases/LG-MICROSOFT-20261006-001.md). 날짜는 회의일이다. 공식 게시가 상대 시간을 표시해 절대 발행일은 확정하지 않았다.

양사는 제조 데이터를 수집해 모델을 훈련하고 다시 데이터 수집으로 돌아가는 Data Flywheel을 추진한다. 운영 현장에서 다른 작업·설비·환경을 만났을 때 모델이 어디서 실패하는지 수집해야 다음 학습을 바꿀 수 있다. 이 작동 설명은 기술 해석이다. 그룹 공장의 전체 운영 현황과 작업 성공률은 공개하지 않았다.

### NVIDIA의 개발 도구, Microsoft의 클라우드·업무 플랫폼

NVIDIA는 시뮬레이션·로봇 훈련 도구와 시설·차량 기술 규격을 제공한다. Microsoft는 클라우드 컴퓨팅, 업무 플랫폼, 데이터센터 공급 기회를 연결한다. LG는 두 파트너와 Physical AI를 추진한다. 독점 선택을 확인할 계약 조건은 공개하지 않았다.

**사업 전망:** LG가 Microsoft에 설비를 납품하면 공급 매출이 생기고, 클라우드·업무 플랫폼을 이용하면 사용 비용이 생긴다. 설비 판매와 플랫폼 소비가 같은 관계 안에서 교차한다. 공급액·가격 할인·상계 조건을 공개하지 않아 순수익을 계산할 수 없다.

## 4. AIR 공급계약과 CNS의 기업 AI 채널

### 4.1 AIR가 북미 고객과 현장 서비스를 연결한다

AIR는 북미 HVAC·전기·제어·서비스 기업 플랫폼이다. AIR는 10월 5일, LG는 10월 6일 미국·캐나다 5GW 이상 프로젝트를 지원할 장기 칠러 공급계약을 발표했다. LG는 장비를 제조하고 AIR는 지역 고객·현장 서비스를 연결한다. [AIR 사례](../cases/LG-COOLING-AIR-20261006-001.md)

5GW는 대상 프로젝트 규모다. LG는 계약 총액과 연도별 물량을 공개하지 않았다. 상반기 AIDC 냉각 수주 6,000억원 초과는 냉각 사업의 집계이며 AIR 단일 계약액으로 귀속할 근거가 없다. 공급계약·생산 투자·납품은 [L-1](01_ai_data_center_infra.md)에 정리했다.

### 4.2 CNS가 접근권 공급·데이터 통합·업무 구현을 맡는다

| 협력 | 확보한 권리·역할 | 공개된 실행 근거 | 매출 해석의 범위 |
|---|---|---|---|
| OpenAI | Enterprise 리셀러·서비스 구현, Edu 채널 | 4월 약 10개 기업 고객 확보, Launch Center | 당시 고객 확보; 고객별 사용량·수익 미공개 |
| Anthropic | 그룹 적용 가능한 Claude Enterprise 통합 계약 | CNS 전 임직원 사용 제공·단계적 확장 | 계약 적용 가능 범위와 실제 배포 범위 구분 |
| Palantir | Foundry/AIP 파트너십·전담 FDE | 익명 계열사 품질 PoC 후 본사업 계약 | 그룹 전체 도입·품질 ROI 아님 |

근거: [OpenAI](../cases/LG-OPENAI-CHANNEL-20261006-001.md), [Claude](../cases/LG-CLAUDE-20261006-001.md), [Palantir](../cases/LG-PALANTIR-20261006-001.md). 상세 업무·시장 실적은 [L-4](04_enterprise_ax_agentic_operating_model.md)에서 관리한다.

CNS는 모델 접근권을 공급하고 고객의 데이터·권한·업무 시스템을 연결한다. 출력 검토와 실행 승인도 고객 업무에 맞춰야 한다. OpenAI 채널과 Palantir FDE는 이 작업의 판매·수행 조직을 확보한 사례다. 내부 사용 경험만으로 외부 고객의 ROI를 계산할 수 없다.

## 5. 과학 협력의 실험 책임과 데이터·특허 권리

| 협력 | LG가 제공하는 것 | 파트너가 제공하는 것 | 확인한 권리·결과 범위 |
|---|---|---|---|
| D&D Pharmatech | 후보 설계 모델·서열 제안 | 합성·평가·경구 제형·임상·허가 | 공동개발 역할 공개; 경제적 조건·공동 IP 미공개 |
| GS칼텍스 | Discovery 기반 소재 연구 | 냉각유 개발의 산업 소재 역량 | 공동 개발·시료 전시; 공급 고객 미공개 |
| CuspAI | CNS의 데이터 처리·검증 해석·운영 | 에이전틱 소재 설계 플랫폼·연구 생태계 | 공개 데이터/IP 정책; 국내 계약·고객 성과 미공개 |

근거: [D&D](../cases/LG-DD-PEPTIDE-20261006-001.md), [Discovery](../cases/LG-DISCOVERY-20261006-001.md), [CuspAI](../cases/LG-CUSP-MATERIALS-20261006-001.md). 과학 후보·실험의 상세 비교는 [L-5](05_ai_for_science_bio_materials_battery.md)에 연결한다.

CNS는 CuspAI 고객 데이터를 전용 서버에 격리하고 모델 학습에 재사용하지 않는다고 설명했다. 신소재 특허는 의뢰 기업이 갖는다. 공개 플랫폼 정책이다. 개별 고객 계약의 예외 조항과 실제 서버 운영은 검증하지 않았다. 다른 파트너의 계약 조건은 별도다.

CuspAI는 4.5억달러를 조달하고 26억달러 기업가치를 발표했다. LG CNS의 투자액은 이 자료에 없다. Foundry 참여 규모는 7월 20일 CuspAI가 ‘45개 초과’, CNS가 7월 자료에서 ‘48개’로 표시했다. 발표 시점과 집계 정밀도를 함께 기록했다.

**사업 전망:** 소재 기업이 외부 연구 AI를 쓰면 실험 데이터를 플랫폼에 제공하는 과정에서 기술 유출과 결과물 귀속 문제가 발생할 수 있다. CuspAI의 공개 정책은 이 구매 조건을 다룬다. CNS가 데이터 처리·실험 결과 해석·운영을 묶어 제공한다면 고객은 플랫폼 도입을 개별 연구 과제로 시작할 수 있다. 국내 고객 계약과 성과는 아직 공개하지 않았다.

## 6. General Atlantic: AI 도입 채널에서 SW 자산 확보로

CNS와 General Atlantic은 9월 24일 뉴욕에서 공동투자 협약을 체결하고 10월 1일 발표했다. 양사는 기업 SW·AI 회사를 발굴한다. 대상 기업이 확정되면 투자 규모와 조건을 건별 공개할 계획이다. 완료한 인수 대상과 지분율은 미공개다. [GA 사례](../cases/LG-GENERAL-ATLANTIC-20261006-001.md)

| 기존 사업과의 연결 | 회사가 설명한 확장 방향 | 조사 해석 |
|---|---|---|
| IT서비스·AX 구축 | IP를 가진 SW 자산 확보 | 프로젝트 수행 외에 제품 수익 기반 추가 |
| 고객별 통합·운영 | 라이선스·구독 매출 강화 | 같은 제품을 여러 고객에게 제공할 가능성 |
| 국내 산업 고객 기반 | 인수 SW 기술·고객을 활용한 북미·아태 확대 | 제품과 기존 고객 관계를 함께 확보하려는 방향 |
| Agentic AI 실행 | 핵심 업무·데이터를 다루는 기업 SW 연계 | Agent가 실행할 시스템·권한·업무 구조의 중요성 |

**사업 전망:** CNS가 제품 IP를 확보하면 같은 SW를 여러 고객에게 라이선스·구독으로 판매하고 구축·운영 서비스를 추가할 수 있다. 인수 기업의 고객 기반은 AX 서비스를 판매할 접점이 된다. 다만 제품 유지보수·보안·고객별 통합 비용이 남는다. 이 비용과 추가 판매 실적이 공개돼야 반복 매출과 수익성의 변화를 평가할 수 있다.

GA의 6월 말 운용자산은 1,300억달러다. LG의 투자 예산과 공동펀드 규모는 공개하지 않았다. CNS는 제품 IP와 고객 기반을 확보하려 하지만 대상·거래 구조를 공개하기 전에는 수익 배분과 인수 효과를 계산할 수 없다.

## 7. 계약·제품 자격·사용 제공 이후의 거래

| 이미 구체화된 것 | 협력 방향이 명확하지만 결과가 남은 것 |
|---|---|
| AIR 장기 공급 본계약·CDU 제품 자격 | Microsoft 특정 센터 발주·전사 배포 |
| OpenAI 고객 확보·CNS Claude 사용 제공 | 파트너별 활성 사용·업무 ROI·계약 수익 |
| Palantir 품질 PoC 후 본사업 계약 | 전면 운영의 품질·비용 성과 |
| 소재 공동 개발·양재 일부 데이터 수집 | 신약 후보 시험·국내 CuspAI 고객·로봇 현장 성능 |
| GA 공동투자 협약 | 투자 대상·조건 확정·거래 완료 |

LG는 NVIDIA의 개발 도구, Microsoft의 클라우드·업무 플랫폼, 외부 과학 AI를 이용하면서 자체 EXAONE과 산업 제품을 개발한다. AIR는 공급 본계약, CNS의 기업 AI는 고객 확보·사용 제공·본사업 계약까지 진행했다. Microsoft 공급과 GA 투자는 다음 거래를 기다리는 단계다.

**사업 전망:** 냉각·전력·시설을 묶으면 고객이 공급자별 사양을 맞추는 작업을 줄일 여지가 있다. 모델·데이터·업무 실행을 묶으면 CNS가 도입 이후의 통합·운영까지 맡을 수 있다. LG가 이 범위를 판매 계약으로 확보할 때 계열사 협력이 고객에게 제공하는 서비스 범위로 바뀐다. 현재 공개 자료에는 전체 협력을 묶은 단일 계약과 통합 매출이 없다.
