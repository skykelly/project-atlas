# L-4. Enterprise AX / Agentic Operating Model

[LG Group 목차](../README.md) · [조사 이력](../LOG.md)

조사 기준: 2026-01-01~2026-10-06 공개 자료. 사실·수치의 공식 원문, 발표일, 근거 위치와 한계는 연결한 사례에서 관리한다. **원문 확인은 독립 성과 검증을 뜻하지 않는다.** 아래 전략적 종합과 평가 기준은 조사자의 해석이다.

## 1. 챗봇 도입과 기업 AX의 차이

기업 AX는 업무에 AI를 덧붙이는 것뿐 아니라 데이터·판단·실행·승인의 흐름을 다시 설계하는 일이다. 보고서를 빨리 만드는 도구와 품질 리스크를 파악해 다음 조치를 제안하는 운영 체계는 요구하는 데이터와 권한이 다르다. LG의 공개 자료에서도 개인 생산성, 현업 Agent, 데이터 운영 플랫폼, 기업 시스템 개발이 별도의 경로로 나타난다.

2026년 LG전자의 전사 생산성 목표와 LG화학의 교육 실적은 방향과 확산의 근거다. CNS의 고객 계약·프로젝트 적용은 사업화 근거다. 이를 하나의 그룹 생산성 숫자로 합치지 않는다.

## 2. 누가 어떤 역할을 맡는가

| 역할 | 공개 자료에서 보이는 주체·수단 | 실제 판단에 필요한 것 |
|---|---|---|
| 경영 우선순위 | 전자 QCD·전사 AX 목표 | 과제별 비용·품질·납기 기준 |
| 모델·전문 지식 | AI연구원 EXAONE, 외부 모델 병행 | 업무별 정확도·비용·데이터 경계 |
| 현업 문제 정의 | 화학 교육·1인 1에이전트 | 실제 반복 사용·업무 품질·권한 |
| 데이터 운영 통합 | CNS Foundry·AIP·FDE | 품질·재고·생산 등 객체·관계의 일관성 |
| 개발·배포 | CNS AIND·지식 파운데이션 | 명세·보안·기존 시스템·회귀 검증 |
| 외부 공급 | CNS OpenAI·Anthropic 채널 | 고객별 계약·도입·운영 성과 |

이 역할표는 확인한 사례를 묶은 해석이며 그룹 공통 조직도가 아니다. 특히 EXAONE을 개발한다는 사실과 전 계열사가 자체 모델만 사용한다는 설명은 다르다. 전자 LGenie와 CNS의 외부 공급 계약에서는 복수 모델·플랫폼을 활용하는 방향이 확인된다.

## 4. Agentic Operating Model의 실질적 구성

1. **업무 객체를 정의한다.** 제품·주문·설비·품질 이슈·고객 등 같은 대상을 부서마다 다르게 해석하지 않도록 맞춘다.
2. **근거와 권한을 연결한다.** Agent가 읽을 수 있는 데이터와 실행할 수 있는 행동을 작업·사용자별로 제한한다.
3. **작업을 역할로 분해한다.** 분석·계획·코딩·검사 등 전문 Agent의 입출력과 책임을 명시한다.
4. **명세와 승인으로 실행을 통제한다.** 고위험 변경에는 사람의 승인, 실행 후 검증과 취소·복구 절차를 둔다.
5. **업무 성과로 운영한다.** 처리 시간·재작업·결함·비용·사람 개입률을 모델 비용과 함께 본다.

이 구성은 AIND의 명세·지식 기반과 Foundry·AIP의 운영 데이터 연결을 참고한 조사자의 실행 틀이다. 모든 LG 업무에 적용된 공통 표준으로 단정하지 않는다. 데이터가 정리되지 않은 상태에서는 Agent 수를 늘려도 서로 다른 전제에서 판단하며 오류를 확대할 수 있다.

## 5. 자체 역량과 외부 플랫폼의 선택

| 선택 | 적합한 과제에 대한 해석 | 확인해야 할 비용·위험 |
|---|---|---|
| 자체·산업 특화 모델 | 내부 지식·산업 문제를 깊게 반영하는 과제 | 모델 유지·평가·배포·데이터 투자 |
| 범용 기업 AI | 문서·코딩·협업에서 빠르게 활용하는 과제 | 좌석·사용량·연결 권한·변경 대응 |
| 데이터 운영 플랫폼 | 여러 시스템의 상태를 묶어 판단하는 과제 | 데이터 정합성·통합 비용·종속성 |
| 개발 Agent | 기존 코드·표준·보안 규칙을 이해하는 개발 | 회귀 결함·검토 부담·운영 책임 |

‘자체 모델 또는 외부 모델’만 고르는 문제가 아니다. 어떤 모델을 써도 업무 시스템의 맥락과 실행 통제가 필요하다. CNS가 여러 공급 채널을 확보하는 의미는 모델 선택을 넓히는 데 있으며, 각 고객의 데이터를 안전하게 연결하고 결과를 검증하는 능력이 실제 서비스의 차이를 만든다.

## 6. 비교 종합과 성과 판단

**조사 해석:** LG의 AX는 모델 확보, 현업 사용, 데이터 운영 통합, 개발·서비스 사업화를 병행하는 구조다. 공개 근거는 교육·도입 계약·PoC 본사업 전환까지 구체적이지만, 전사 단위 실현 ROI를 입증하는 비교 자료는 제한적이다.

| 평가 대상 | 권장 분모·조건 | 현재 자료에서 피해야 할 해석 |
|---|---|---|
| 현업 확산 | 대상 인원 중 반복 활성 사용자·업무 수 | 수료자=상시 사용자 |
| 생산성 | 동일 업무·품질·기간의 순 작업 시간 | 단일 작업 절감=전사 절감 |
| 개발 | 기능 규모·결함·회귀 검증·운영 유지비 | 코드 생성 속도=프로젝트 완결 속도 |
| 사업화 | 유료 계약·실제 가동·갱신·매출 인식 | 협약·사용 가능 범위=전체 도입 완료 |
