# L-3. AI Mobility / SDV·AIDV

[LG Group 목차](../README.md) · [조사 이력](../LOG.md)

**조사 기간: 2026-01-01~2026-10-06.** 공식 회사·고객·플랫폼 원문을 확인했다. 수치의 출처·발표일·측정 조건은 연결한 사례 문서에 기록했다. 아래 사업적 의미와 비교 종합은 조사자의 해석이며, 회사 발표와 독립 성과 검증은 구분한다.

## 1. 전장 공급 기반 위에 차량 AI를 얹는다

LG의 모빌리티 AI는 완성차 한 대를 만드는 사업보다 **차량 안의 정보·컴퓨팅·통신·센싱·화면·배터리 지능을 OEM에 공급하는 사업**으로 이해해야 한다. 2026년 공개 자료에서는 두 속도가 나타난다. 콕핏과 통신은 실제 공급으로 연결됐고, 생성형 AI Cabin과 새로운 화면·센싱 조합은 전시·제안 단계가 중심이다.

SDV(Software-Defined Vehicle)는 차량 기능을 소프트웨어로 관리·갱신한다. AIDV(AI-Defined Vehicle)는 이 구조에 상황 이해와 반응을 더한다. 콕핏 제어기 납품과 AI 판단 기능의 양산은 서로 다른 성과다. LG는 전장에서 현금을 만들고, AI 기능에서 추가 가치를 노린다.

| 핵심 결과 | 구체적 근거 | 사업적 의미 |
|---|---|---|
| 전장 사업은 이미 매출 기반을 갖춤 | VS 2026년 2분기 매출 3.03조원·영업이익 1,910억원 | AI 콘셉트를 기존 OEM 개발·공급 관계에 연결할 기반 |
| 특정 고객·차종의 SDV 공급 확인 | Renault New Trafic E-Tech Electric 통합 콕핏 | 전시를 넘어 OEM 프로그램에 들어가는 사업 |
| 통신 통합 제품은 양산·납품 개시 | 8월 유럽 프리미엄 OEM 스마트 텔레매틱스 | SW 갱신·연결 서비스의 물리적 기반 공급 |
| AI 경험의 차별화 방향은 구체화 | CES 온디바이스 AI·탑승자 상태·맥락 반응 | 화면과 콘텐츠에서 상황 이해·개인화로 가치 확대 |

근거: [VS 실적](../cases/LG-VS-RESULTS-20261006-001.md), [Renault](../cases/LG-RENAULT-COCKPIT-20261006-001.md), [텔레매틱스](../cases/LG-TELEMATICS-20261006-001.md), [AI Cabin](../cases/LG-AIDV-CABIN-20261006-001.md). VS 매출은 전장 사업 전체이며 생성형 AI 매출로 분류하지 않는다.

## 2. 시장 변화: 부품을 연결하던 차량에서 공통 SW 기반으로

OEM이 차량 기능마다 별도 제어기·SW를 개발하면 화면·앱·통신 기능이 늘 때 통합 부담도 커진다. 2026년 Google은 AAOS를 인포테인먼트 밖으로 확장하는 **AAOS SDV** 방향을 발표했다. 3월 24일 원문은 비안전 영역(non-safety parts)의 공통 기반을 명시하고 Renault·Qualcomm과의 협업, 연내 오픈소스 공개 계획을 설명한다. LG의 5월 AAOS 발표는 이 생태계에서 여러 화면과 차종별 경험을 구현하는 역할을 명시한다.

| 시장의 변화 | OEM의 문제 | LG가 공급하는 접점 |
|---|---|---|
| 화면과 사용자별 콘텐츠 증가 | 제어기·배선·연산 부하가 늘어남 | 단일 SoC 다중 화면 제어·자원 배분 |
| 차량 기능의 지속 갱신 | 출고 뒤에도 SW를 유지해야 함 | OTA를 지원하는 통신·콕핏 SW |
| 탑승자별 개인화 | 같은 차 안에서 요구가 다름 | 개별 로그인·화면·음성 UX·센싱 |
| 배터리 상태의 지속 관리 | 같은 배터리도 사용 조건이 다름 | 진단·열화 예측·충전 행동 SW |

Google이 공통 플랫폼을 제공해도 차종별 화면 배치·하드웨어·성능 조건을 맞추는 일은 남는다. LG의 기회는 OS 자체 소유보다 **OEM의 구체적인 차량에 플랫폼을 구현하고 운영하는 통합 능력**에 있다. Google의 비안전 영역 설명을 근거로 AAOS SDV를 자율주행 전체 제어·안전 인증과 동일시하지 않는다. [Google·LG 원문](../cases/LG-AAOS-COCKPIT-20261006-001.md)

## 3. Renault: 고객과 차종이 드러난 공급 사례

### 3.1 실제 공급 범위

10월 6일 LG 발표는 New Trafic E-Tech Electric의 **계기판과 인포테인먼트를 통합한 콕핏**을 대상으로 한다. 계기판은 속도·RPM·경고 정보를, 인포테인먼트는 내비게이션·미디어를 담당한다. LG는 개발·전달 사실을 설명하면서 공급 예정 표현도 사용한다. 계약 금액·대수와 차량 고객 인도 완료는 공개하지 않았다.

하나의 제어 틀이 주행 정보와 콘텐츠를 함께 구성한다. OEM은 부품·설계 복잡도를 줄이고 UX를 일관되게 만들 수 있다. LG의 공급 범위도 개별 화면·기능에서 콕핏 영역 통합으로 넓어진다. 비용 감소율은 공개되지 않았으므로 금액으로 환산하지 않는다.

### 3.2 공급 발표와 차량 출시 일정

| 날짜 | 공식 자료의 내용 | 단계 해석 |
|---|---|---|
| 2026-02-23 | Renault가 Sandouville에서 신형 Trafic 생산을 연말 시작할 계획 발표 | 완성차 생산 일정 계획 |
| 2026-10-06 | LG가 해당 차량의 통합 콕핏 개발·전달 및 공급 발표 | 차종 특정 부품·SW 공급 근거 |
| 조사 기준일 | 양산 차량 판매량·LG 공급 대수 미공개 | 고객 차량 인도 실적과 구분 |

기존 Trafic E-Tech와 새 SDV 모델은 이름이 비슷해 기존 전기 밴의 판매·생산 이력을 새 SDV 실적으로 옮기기 쉽다. 이 보고서는 **New Trafic** 프로그램의 자료만 연결한다. 차량의 SDV 채택은 확인되지만 LG AI Cabin의 생성형 AI까지 탑재했다는 근거는 없다. [LG·Renault 원문과 범위](../cases/LG-RENAULT-COCKPIT-20261006-001.md)

## 4. 단일 SoC 다중 화면: 고객 경험과 시스템 원가의 접점

5월 28일 공개한 AAOS 기반 솔루션은 Qualcomm 차세대 Snapdragon Cockpit을 이용해 서로 다른 비율의 화면을 하나의 SoC에서 제어한다. 운전자는 내비게이션, 동승자는 영상, 뒷좌석은 별도 콘텐츠를 이용하는 예시를 제시했다. 개별 로그인·설정·공유·부모 통제와 음성 화면 조작도 포함한다.

여러 화면은 같은 연산 자원을 놓고 경쟁한다. 시스템은 자원을 배분하고 부하를 제어하면서 차량 정보를 끊김 없이 전달해야 한다. LG가 설명하는 자원 배분·부하 최적화가 이 문제를 다룬다. 동일 경험을 더 단순한 구성으로 구현할 수 있으면 OEM의 하드웨어 선택과 개발 공정에 영향을 준다.

| 요소 | 사용자에게 보이는 결과 | OEM 통합 관점의 의미 |
|---|---|---|
| 화면별 콘텐츠·계정 | 좌석별로 다른 경험 | 사용자·앱 상태를 분리해 관리 |
| 단일 SoC 제어 | 여러 화면이 동시에 작동 | 제어기 구성을 단순화하는 방향 |
| 음성 레이아웃 조작 | 대형 화면을 손으로 찾는 부담 감소 | UI와 시스템 명령의 연결 |
| SW·칩 호환 방향 | 다양한 차종에 구현 가능 | 플랫폼 변경 때 재사용 여지 |

발표는 솔루션 공개와 기술 협력의 근거다. 최대 화면 수·프레임·전력·비용 감소율·양산 고객은 미공개이므로 Renault 프로그램에 같은 사양이 그대로 적용됐다고 단정하지 않는다. [AAOS 사례](../cases/LG-AAOS-COCKPIT-20261006-001.md)

## 5. AI Cabin: 무엇을 이해하고 어떻게 반응하는가

AI Cabin의 상세 사양은 2025년 12월 11일 CES 2026 사전 발표이고, 2026년 1월 전시 원문이 실제 시연을 설명한다. Snapdragon Cockpit Elite에서 VLM·LLM·이미지 생성 모델을 차량 내 처리하는 방향이다. 외부 서버 왕복 없이 반응하고 영상 전송을 줄이는 설계 취지지만 지연·전력의 측정값은 공개하지 않았다.

| 입력·상황 | 발표에 나온 반응 | 기존 IVI와 달라지는 점 |
|---|---|---|
| 외부 차량 합류와 운전자 주의 | 운전자가 놓친 상황을 언어로 경고 | 외부 환경과 운전자 상태를 함께 해석 |
| 눈 내리는 밤·음악 재생 | 상황에 맞춘 배경 이미지·음악 제안 | 정해진 메뉴에서 맥락에 맞는 표현 생성 |
| 시선·주의·탑승자 상태 | 상태에 따른 상호작용 | 같은 알림을 모두에게 보내는 방식에서 개인화 |

CES에서는 전면 유리 정보 표시, Automotive Vision의 시선·상태 감지, 가정과 차량 간 콘텐츠 연결 등을 보여줬다. 제품 흐름은 센서→상황 해석→표시·언어 반응으로 이어진다. 반면 운전 경고와 엔터테인먼트는 실패의 영향이 다르다. 개인화 시연은 자율주행 등급이나 안전 검증을 대신하지 않는다. [시연·사전 사양 근거](../cases/LG-AIDV-CABIN-20261006-001.md)

## 6. 이노텍·디스플레이: AI 경험을 가능하게 하는 입력과 출력

### 6.1 센싱은 모델 앞단의 품질 문제다

이노텍은 CES 목업에 AD/ADAS 16종 제품을 배치하고 카메라·LiDAR·레이더와 SW를 묶어 제안했다. Aeva 공동 LiDAR의 최대 200m 감지, 계기판 뒤 언더디스플레이 카메라의 AI 화질 복원, UWB 기반 아동 감지 등을 공개했다. 카메라가 가려지거나 오염됐을 때 입력 품질을 유지하는 기술도 중요한 접점이다.

**해석:** AI 판단의 상한은 센서가 확보한 입력 품질에서 결정된다. 광학·센서·복원 SW를 묶으면 이노텍은 개별 부품 규격뿐 아니라 사용 조건에서의 입력 품질을 제안할 수 있다. 다만 200m는 최대 거리 발표이며 날씨·반사율·탐지 확률이 동일한 경쟁 제품 비교값은 아니다. 목업은 고객 차량 양산 채택과 구분한다. [이노텍 사례](../cases/LG-INNOTEK-AIDV-20261006-001.md)

### 6.2 화면은 공간·운행 상태에 따라 달라진다

디스플레이는 51인치 단일 OLED P2P와 30R로 말아 숨겼다가 33인치로 확장하는 슬라이더블 콘셉트를 공개했다. P2P는 운전석~조수석을 잇는 화면, 슬라이더블은 주행 때 작은 표시 공간과 정차·자율주행 모드의 확장 공간을 제안한다.

**해석:** 개인화 콘텐츠가 늘면 표시 공간도 좌석·상황별로 달라진다. 유연한 패널은 그 공간을 만드는 부품이고, 전자의 콕핏 SW는 무엇을 어디에 표시할지 구현하는 영역이다. 두 기술이 보완적이라는 사실과 같은 고객의 통합 채택은 구분한다. [패널 사양·공개 단계](../cases/LG-DISPLAY-SDV-20261006-001.md)

## 7. 출고 이후: 통신과 배터리 SW가 차량 생애주기를 연결한다

### 7.1 텔레매틱스의 양산 근거

8월 19일 발표는 5G R16 통신 모듈과 최대 12개 안테나의 통합 제품이 유럽 프리미엄 OEM에 양산·납품되기 시작했음을 명시한다. 보드 결합·분리 옵션과 자체 ATP(Automotive Telematics Platform) 기반 SW 재사용도 설명한다. 칩셋 인터페이스를 바꾸면서 공통 코어 SW를 유지하는 구조다.

이 제품은 OTA·V2X·데이터 전달을 지원한다. AI 모델의 성능을 직접 높인다는 근거보다, 출고 후 기능 갱신에 필요한 연결 장치의 공급 실적으로 읽는다. [텔레매틱스 사례](../cases/LG-TELEMATICS-20261006-001.md)

### 7.2 배터리 지능의 상품 구성

| SDVerse 제공 SW | 기능 | 고객 활용의 접점 |
|---|---|---|
| Battery Platform SW | 배터리 상태·BMS 기능 통합 | SDV 구조에 배터리 상태 연결 |
| Safety Diagnostic Calibration Tool | 진단·시뮬레이션 검증 | 고객 자체 분석·보정 |
| Onboard FRISM | 현장 데이터와 ML 오차 보정으로 SOH 추정 | 열화 상태 진단 |
| Onboard BLiS | 물리 모델 기반 열화·성능 예측 | 사용 조건과 급속충전 능력 시뮬레이션 |
| Onboard DASH | 주행·충전 행동의 열화 영향 분석 | 수명 관리 행동 안내 |

4월 3일 마켓플레이스 참여는 셀 공급 이외에 알고리즘·SW를 OEM이 찾고 평가하는 채널을 확보했다는 의미다. 진단→예측→행동 안내가 연결되지만 다섯 SW 모두 생성형 AI는 아니다. 고객 구매·탑재·라이선스 매출은 공개하지 않았다. [SDVerse 근거](../cases/LG-BATTERY-SDVERSE-20261006-001.md)

## 8. 비교 종합: LG가 고객에게 제공하는 가치와 사업 성숙도

| 사업 접점 | 현재 근거 | 수익 기회에 대한 해석 |
|---|---|---|
| 콕핏 통합 | 차종 특정 공급 | OEM 프로그램 단위 HW·SW·개발·지원 |
| 연결성 | 익명 OEM 양산·납품 | 여러 차종에 통신 모듈·SW 재사용 |
| 차량 내 AI | 시연·플랫폼 사양 | 기존 콕핏 공급에 상황 이해·개인화 기능 확대 |
| 센싱·화면 | 부품·콘셉트 제안 | AI 입력·출력 품질과 공간 설계 차별화 |
| 배터리 SW | 제공 채널 확보 | 배터리 생애주기 지능의 SW 상품화 |
