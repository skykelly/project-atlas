# L-2. Physical AI / Smart Manufacturing

[LG Group 목차](../README.md) · [조사 이력](../LOG.md)

**조사 기간: 2026-01-01~2026-10-06.** 아래 사실은 연결된 사례의 공식 원문을 확인했다. 회사의 사업 발표·내부 측정과 독립 검증은 구분한다. 사업적 의미와 비교 종합은 조사자의 해석이다.

## 1. 스마트팩토리는 팔고, 로봇 학습 체계는 쌓는다

LG의 제조 AI에는 서로 다른 두 개의 시간이 흐른다. 스마트팩토리는 이미 외부 수주를 만든다. 로봇 사업은 학습·관제·데이터 체계를 구축하고 있다. 2026년 공개 근거는 **기존 공장 경험의 외부 판매, 설비 데이터·품질 AI, 이기종 로봇 학습·관제, 로봇 데이터팩토리** 네 층으로 나뉜다.

| 층 | 실제 공개 결과 | 현재 사업·기술 단계 |
|---|---|---|
| 공장 전환 서비스 | 전자 2025년 외부 스마트팩토리 수주 약 5,000억원을 2026년 공식 인터뷰에서 소개 | 외부 고객 사업화 |
| 설비·MES | Factova 누적 10만대 이상 설비 적용; 익명 고객 공정 성과 | 제품·서비스 운영 |
| 로봇 학습·관제 | Forge 20건 이상 PoC; Baton의 복수 로봇 운영 사례 | PoC·시연 및 제한된 운영 근거 |
| 로봇 데이터 | 양재에 공정·가정·물류 학습 공간, 일부 로봇 데이터 수집 | 구축·수집 중; 연말 확대 목표 |

근거: [전자 스마트팩토리](../cases/LG-SMART-FACTORY-20261006-001.md), [Factova](../cases/LG-FACTOVA-20261006-001.md), [PhysicalWorks](../cases/LG-PHYSICALWORKS-20261006-001.md), [데이터팩토리](../cases/LG-DATA-FACTORY-20261006-001.md).

## 2. 전자: 공장 운영 경험을 외부 프로젝트로 판다

### 2.1 무엇을 판매하는가

LG전자는 진단·설계·자동화·가동 안정화·개선까지 공장 생애주기를 다루는 서비스를 제시한다. 고객의 설비 배치, 병목 공정, 물류 동선과 생산 데이터를 함께 검토하는 구조다. 글로벌 60여 공장의 경험과 약 770TB 제조 데이터가 배경 자산으로 제시된다. 해당 데이터 규모만으로 모델 성능이나 고객 절감을 입증할 수 없다. 다만 새 설비를 설계할 때 실제 운영 지식을 재사용할 기반은 된다.

기존 공장에서 공정 제어·물류·검사를 바꾸어 얻은 결과를 외부 제조사의 공정에 맞추어 적용하는 것이 이 사업의 출발점이다. 같은 설비를 그대로 옮기기보다 고객 제품과 불량 유형·사이클 시간을 고려해 자동화 범위를 선택한다. 이 때문에 수익의 본질은 단일 로봇 판매보다 공장 전환 프로젝트와 안정화 서비스에 가깝다.

### 2.2 공개 성과의 구체적 범위

| 항목 | 회사가 소개한 수치 | 읽는 기준 |
|---|---|---|
| 창원 공장 | 생산성 17% 개선·자동화율 45% | 기존 Lighthouse 사례; 2026년 신규 휴머노이드 효과 아님 |
| 테네시 공장 | 자동화율 60%·불량 61% 감소·검사 사이클 22% 단축 | 기존 공장 사례; 지표별 분모·기간 상세는 공개 제한 |
| 외부 사업 | 2025년 연간 수주 약 5,000억원 | 2026년 인터뷰에서 확인한 전년도 실적; 매출 아님 |
| 사업 목표 | 2030년 연간 수주 10억 달러 규모 | 미래 목표; 원화 1조원과 동일 수치로 쓰지 않음 |

수치는 LG의 제조 전환 역량과 외부 구매 수요를 뒷받침한다. 기존 공장의 자동화 성과를 새 로봇의 전면 대체 성과로 옮길 수는 없다. 외부 수주도 고객별 동일 개선률을 보장하지 않는다. [측정 맥락과 원문](../cases/LG-SMART-FACTORY-20261006-001.md)

## 3. CNS Factova: 데이터를 모으는 제품에서 공정 행동을 바꾸는 플랫폼으로

Factova는 MES를 중심으로 다른 제조사의 설비 데이터를 연결한다. 현장에서는 같은 온도·진동·전류라도 장비마다 읽는 형식과 주기가 다르다. 이 데이터를 표준화하지 않으면 공정 결과와 설비 상태를 연결하기 어렵다. Factova Control은 이 접점을 다루고, 생산 실행·공정 분석·예지보전이 그 위에서 이루어진다.

| 실제 작업 흐름 | 처리하는 정보 | 현장의 변화 |
|---|---|---|
| 설비 데이터 수집 | 모터 전류·온도·진동 등 | 사람이 기록하던 상태를 지속 수집 |
| 표준화·MES 연결 | 설비 ID·공정·생산 이력 | 어떤 조건에서 어떤 제품을 만들었는지 연결 |
| 이상 탐지·예측 | 장비 상태와 품질 결과 | 고장·불량 징후를 먼저 찾아 대응 |
| 안전 기록·검색 | 사진·음성·사고 이력 | 기록 부담을 줄이고 유사 사례 대응 안내 |

5월 20일 공식 발표는 누적 10만대 이상 설비 적용을 소개한다. 고객 사례 중 익명 배터리 제조사는 도입 1개월 뒤 양품 비율 90% 이상과 반품 비용 약 70% 감소, 익명 전자 제조사는 생산성 약 20% 개선과 공정 데이터 약 90% 자동 수집을 제시했다. **양품 비율 90%는 도달 수준이지 90% 증가가 아니다.** 서로 다른 고객의 수치를 하나의 프로젝트 ROI로 합산할 수도 없다.

제조 AI는 생산 이력과 장비 데이터를 먼저 연결해야 작동한다. Factova는 설치된 설비를 유지한 채 필요한 기능부터 모듈로 붙인다. 전체 공장을 바꾸기 어려운 제조사의 구매 조건에 맞춘 접근이다. 고객명·기존 양품률·비용 산식은 미공개다. [Factova 근거](../cases/LG-FACTOVA-20261006-001.md)

## 4. 제조 특화 모델: 공정 예측과 시각 검사는 서로 다른 문제다

9월 공개된 전문가 AI는 제조 데이터를 동일한 방식으로 처리하지 않는다. Tabular는 공정 조건과 품질처럼 표 형태로 축적된 정보에, Omni-Inspect는 검사 이미지와 제품 변화에 대응하는 방향이다. 이노텍과의 협업은 AI가 일반적인 문서 답변을 넘어 현장 품질 판단에 들어가는 사례다.

| 도구 | 입력·문제 | 기대되는 운영 변화 | 공개 수준 |
|---|---|---|---|
| Tabular | 공정 조건·품질 수치 | 조건과 결과 관계를 예측해 의사결정 지원 | 특화 모델 공개·제조 적용 설명 |
| Omni-Inspect | 제품·결함 이미지 | 제품이 바뀔 때 검사 모델 재개발 부담 축소 | 재학습 없이 대응하는 기능 설명 |
| 비전 에이전트 방향 | 샘플링·라벨링·학습 흐름 | 검사 모델 구축 작업의 자동화 | 준비·개발 방향 |

모델이 불량을 찾아도 실제 공정 조건 변경은 별도의 운영 결정이다. 검사→원인 분석→조건 변경→재검사의 폐루프가 완성돼야 생산 결과에 영향을 준다. 공개 자료는 기술의 방향과 협업을 보여주지만 고객 전체 라인의 정확도·불량 감소율을 공통 수치로 제시하지 않는다. [제조 특화 AI 사례](../cases/LG-EXPERT-MFG-20261006-001.md)

## 5. PhysicalWorks: 로봇을 학습시키는 Forge와 일하게 하는 Baton

로봇 한 대의 집기 작업은 물체·행동 학습에 달렸다. 수십 대의 동시 작업은 작업 할당·교통·설비 상태·예외 처리에서 막힌다. CNS는 두 문제를 Forge와 Baton으로 나눈다.

### 5.1 Forge의 학습·검증 흐름

1. **작업 공간을 재현한다.** 3D 시뮬레이션으로 로봇과 물품·설비의 관계를 구성한다.
2. **학습 데이터를 구성한다.** 실제 데이터와 시뮬레이션 데이터의 품질을 선별하고 작업 학습에 사용한다.
3. **투입 전 행동을 검증한다.** 실패·충돌·작업 조건을 점검한 뒤 현장 적용으로 연결한다.

회사는 20건 이상 PoC와 작업 학습·검증·투입 기간을 1~2개월로 줄일 수 있다는 설명을 공개했다. 이 기간은 모든 작업에서 실측한 공통 평균이 아니다. 영상·모션캡처 확대 계획도 현재 기능과 분리한다.

### 5.2 Baton의 운영 흐름

| 상황 | 관제에서 처리하는 것 | 생산 현장에서 중요한 이유 |
|---|---|---|
| 여러 제조사의 로봇 도입 | 상태·명령 인터페이스 표준화 | 로봇별 시스템을 따로 운영하는 부담 감소 |
| 작업이 몰리는 구간 | 수학적 최적화로 할당·경로 조정 | 정체와 대기 시간을 줄이는 방향 |
| 컨베이어 중단·로봇 실패 | 대체 로봇·경로·작업 재배치 | 개별 실패가 전체 작업 중단으로 번지는 것을 완화 |
| 복수 로봇의 같은 공간 사용 | 충돌·우선순위 관리 | 안전과 처리량을 함께 관리 |

부산 스마트시티에서는 순찰·바리스타·짐 운반·청소 네 유형 운영이 소개됐다. 이것은 복수 로봇의 통합 운영 근거지만 대규모 공장 휴머노이드 양산 운영의 증거는 아니다. AMR·AGV 100대 조건의 생산성 약 15% 개선·운영비 최대 18% 절감은 **기대 효과**로 발표됐다. [PhysicalWorks 사례](../cases/LG-PHYSICALWORKS-20261006-001.md)

## 6. 양재 데이터팩토리: 제조 경험을 로봇 학습 자산으로 바꾸기

8월 공식 발표의 양재 시설은 지하 1층·지상 3층, 연면적 1만㎡다. LG CLOiD가 청소를 반복하는 가정 공간, 테네시 세탁기 공정을 모사해 부품 이동·적재·조립을 학습하는 공간, CNS 물류와 이노텍 로봇 손 학습 공간을 함께 둔다. 서로 다른 계열사의 자산을 하나의 데이터 생성 체계로 모은다는 점이 그룹 전략의 구체적인 내용이다.

**테네시 공정 모사 공간에서 로봇이 학습한다는 사실을 테네시 실제 생산 라인의 상용 투입으로 바꿔 쓰지 않는다.** 공식 원문은 일부 로봇 배치·수집을 설명하는 동시에 연말 풀가동과 확대를 목표로 제시한다.

| 단계 | LG·NVIDIA 역할 | 데이터가 늘어나는 방식 |
|---|---|---|
| 실제 수집 | LG 공정·물류·가정 로봇과 학습 공간 | 현장에서 필요한 동작·물체·실패 상황 확보 |
| 공간·행동 재현 | Omniverse·Isaac 개발 체계 | 실제 장면을 검증·시뮬레이션으로 연결 |
| 합성·증강 | Cosmos 세계 모델 | 조건·장면을 확장한 학습 자료 생성 |
| 모델 개선 | LG RFM 학습 | 데이터를 학습해 새로운 행동 성능 개선 |
| 재수집 | 개선한 로봇을 다시 작업에 적용 | 실패·변화 정보를 다음 학습에 반영 |

10만 시간은 2026년 말까지 직접 수집과 합성·증강을 합한 목표다. 약 12년이라는 표현은 시간 환산이며 12년 현장 운전 경험이나 모든 작업의 숙련도와 같지 않다. 여러 계열사의 작업이 한 곳에 모여 있다는 점은 데이터 다양성을 높일 기반이지만, 실제·합성 비중과 성공률 개선 수치는 아직 공개되지 않았다.

공장 수와 데이터 총량만 늘려서는 로봇이 작업을 배우지 못한다. 센서·행동·작업 결과를 연결하고 실제 상황에서 다시 검증해야 한다. 양재 데이터팩토리는 이 루프를 반복한다. [국·영문 원문과 조건](../cases/LG-DATA-FACTORY-20261006-001.md)

## 7. 외부 물류: 청라 검증이 제조 연구와 다른 이유

CNS와 **외부 협력사 LX판토스**의 청라 물류센터 협력은 실제 물류 공정에서 휴머노이드·셔틀 등을 검증하는 경로다. 물류는 물품 종류와 작업 순서가 바뀌기 때문에 고정 반복 공정과 다른 실패 조건을 제공한다. 고객 현장 검증은 연구실 밖의 실패 조건을 드러낸다. 그러나 6월 발표 단계는 업무협약·검증 계획이다. 전 공정 상용화 실적은 아직 없다.

Dexmate의 바퀴형 휴머노이드와 물류 셔틀도 구분해야 한다. 1.5m/s·1,500kg은 셔틀 사양으로 제시된 수치이며 Dexmate 휴머노이드의 운반 성능이 아니다. [청라 물류 사례](../cases/LG-PANTOS-ROBOT-20261006-001.md)

## 8. 비교 종합: 하나의 로봇보다 생산 시스템의 여러 접점

| 축 | LG전자 | LG CNS | AI연구원·이노텍 |
|---|---|---|---|
| 현재 자산 | 공장 설계·운영 경험, 로봇·부품 | MES·설비 연결·물류·SI·관제 | 특화 모델·품질 데이터·검사·부품 |
| 외부 고객에게 판매하는 가치 | 공장 전환과 안정화 | 설비 연결·작업 최적화·통합 운영 | 공정 예측·검사 기능과 산업 적용 |

**종합 판단:** 단기 매출은 기존 설비 데이터와 공정·품질·물류 개선에서 나온다. 차세대 Physical AI는 이 운영 경험을 로봇 학습과 이기종 관제에 연결한다. LG는 두 축을 동시에 확보했다. 스마트팩토리 수주를 휴머노이드 매출로 집계하거나 기존 자동화 성과를 새 로봇의 검증으로 재사용해서는 안 된다. 2026년 이후의 격차는 공장 지식을 외부 상품으로 반복 판매하고, 데이터팩토리의 학습 루프를 고객 현장 성능으로 입증하는 속도에서 벌어진다.
