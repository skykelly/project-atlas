# G-2. Query fan-out·탐색·추천 경로 — G-1에 통합

[주제 목차](README.md) · [통합 본문: G-1 발견·탐색](G-1_ai_search_geo.md)

2026-10-06에 이 주제를 G-1의 발견·비교·추천 과정에 통합했다. Query fan-out은 독립 시장이나 별도 실행 영역보다 고객 질문에 필요한 근거를 탐색하는 방식이며, 기존 G-1의 콘텐츠 준비·질문 대응표와 중복이 컸다.

다음 내용은 [G-1 통합 본문](G-1_ai_search_geo.md)에서 계속 관리한다.

- Google의 공식 RAG·query fan-out 설명과 다른 플랫폼으로 일반화할 수 없는 범위
- 고객 과업·설치·소음·총비용·호환 조건을 분해한 질문-근거 대응표
- 질문별 페이지 증식 대신 필요한 제품 근거를 연결하는 실행 패턴
- 반복 UI/API 관찰과 추천·제약 누락 평가

기존 경로는 과거 링크를 유지하기 위한 안내로 남겼다. 현재 운영 카테고리는 G-1·G-3~G-8의 7개이며 다른 코드와 근거 ID는 변경하지 않았다. 통합 이력은 [LOG](LOG.md)에 기록했다.
