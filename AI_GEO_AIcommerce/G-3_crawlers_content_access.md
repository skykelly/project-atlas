# G-3. AI 크롤러·콘텐츠 접근·llms.txt

[목차](README.md) · [발견·탐색](G-1_ai_search_geo.md) · [측정](G-4_measurement.md)

> **핵심 결론:** 기업은 AI 접근을 검색·학습·사용자 요청으로 구분하고, 접근 허용·정보 읽기·최신 사실 전달을 각각 검증해야 한다. llms.txt 추가보다 실제 제품 페이지의 차단·가독성·정보 정합성을 우선 확인한다.

_조사 창: 2026-01-01~2026-10-06. 근거 확인일: 2026-10-06._
이 문서는 **기술 접근과 정보 전달의 운영 조건**을 다룬다. 무엇을 답변할지는 [G-1](G-1_ai_search_geo.md), 플랫폼 선택은 [G-7](G-7_platform_ecosystems.md), 주문·결제 자격은 [G-5](G-5_agentic_commerce.md)의 범위다.

## 2026년 변화와 현행 기준

| 시점·근거 | 구체적인 확인 내용 | 실무 판단 |
|---|---|---|
| 06-15 [Google llms.txt 명확화](evidence/GOO-LLMS-20261006-001.md) | Google 검색 가시성·순위에 해당 파일의 특별 효력 없음 | 파일 설치를 Google GEO 성과의 선행 조건으로 두지 않음 |
| 07-10 [Google 가이드](evidence/GOO-GEO-20261006-001.md) | 검색 색인·snippet 자격·생성형 AI 포함 설정, JS 접근 조건 안내 | 검색과 AI 접근 조건을 실제 URL·속성별 확인 |
| 현행 [OpenAI 봇 문서](evidence/OAI-CRAWL-20261006-001.md) | 검색·학습 robots 독립, 사용자 요청 조회의 예외 | “AI 전체 차단/허용” 한 규칙으로 처리하지 않음 |
| 현행 [OpenAI 피드](evidence/OAI-FEED-20261006-001.md) | 승인 파트너·Stable·시장별 설정·파일/API 경로 | 웹 crawl과 catalog 연동은 별도 검증 |
| 04·08월 [Adobe 가독성 연구](evidence/ADI-MARKET-20261006-001.md) | 제품 페이지·홈페이지·업종별 읽기 격차 | 개별 사이트/봇 테스트의 필요성, 공급사 점수는 보조 지표 |

Google 가이드·OpenAI 봇·피드·Search Console 문서는 이번 개편 때도 공식 URL을 다시 열어 확인했다. 날짜 없는 문서를 2026년 신규 출시로 표현하지 않는다.

## 봇별 접근 정책 비교

| 식별자·출처 | 목적 | 기업이 결정할 정책 | 오해하기 쉬운 점 |
|---|---|---|---|
| OAI-SearchBot | ChatGPT 검색용 발견 | 공개 제품·지원 정보의 검색 수집 허용 범위 | 허용해도 실제 검색 노출 보장 없음 |
| GPTBot | 기반 모델 학습에 사용할 수 있는 수집 | 학습 목적 수집의 허용/차단 | 검색 봇과 독립 설정 가능 |
| ChatGPT-User | 사용자가 요청한 페이지 방문 | 사용자 조회·인증·접근 정책 | 자동 크롤러가 아니며 robots가 적용되지 않을 수 있음 |
| Google 검색 접근 | 색인과 검색 AI의 근거 이용 | 공개 URL·snippet·속성 설정 점검 | 파일 하나가 전체 포함/제외를 대신하지 않음 |

OpenAI 역할은 [목적별 봇 근거](evidence/OAI-CRAWL-20261006-001.md), Google 조건은 [가이드](evidence/GOO-GEO-20261006-001.md)에 연결한다. 봇 신원은 문자열만으로 신뢰하지 않고 공식 IP 목록 등 문서의 검증 경로와 대조한다. robots는 공개 crawl 지시이며 인증·민감정보 보호 수단을 대체하지 않는다. 검색 차단 후에도 탐색용 링크가 표시될 수 있다.

## 가독성 숫자를 어떻게 읽어야 하는가?

[Adobe](evidence/ADI-MARKET-20261006-001.md)의 2026-04 발표에서 미국 retail 제품 페이지 점수는 평균 66%, 홈페이지는 75%였다. 2026-07 확대 표본에서는 홈페이지 61%, electronics 전반 70%로 보고했다.

이 값은 **Adobe 기계 가독성 도구의 점수**다. 제품 추천 포함률·Google 인용률·정보 정확도·구매 CVR가 아니다. 표본 확대가 있으므로 홈페이지 75→61을 같은 사이트들이 악화된 것으로 계산하지 않는다. 또한 electronics 전반 점수와 제품 페이지만의 점수도 직접 비교하지 않는다.

### 실제 제품 페이지에서 점검할 실패 유형 — 가설

| 실패 유형 | 가전 정보 예시 | 확인 방법·산출물 |
|---|---|---|
| 접근 차단 | 공개 모델 페이지에 지역/봇별 403 | 응답 코드·지역·봇별 차단 이유 |
| 중요한 내용이 이미지에만 존재 | 설치 여유·호환 도표 | HTML/렌더링에서 같은 사실이 읽히는지 대조 |
| 인터랙션 후에만 보이는 정보 | 펼침 탭의 보증·반품 예외 | raw 응답과 실제 렌더링/DOM의 차이 |
| 지역·모델 혼동 | 한국 URL에서 해외 모델/가격 | URL·canonical·언어·모델·통화 대응 |
| 업데이트 불일치 | 웹 재고·피드 재고·가격 차이 | 원천 버전·동기화 시각·오류 모델 목록 |
| 링크/옵션 손실 | 제품 비교 후 기본 옵션으로 이동 | URL 목적지·모델/옵션 유지 여부 |

특정 AI가 모든 JavaScript를 못 읽는다고 가정하지 않는다. Google은 차단되지 않은 JS 처리와 기존 JS SEO 원칙을 안내한다. 플랫폼별 raw HTML·렌더링·사용자 요청 경로를 실제로 비교해야 한다.

## 정보 전달 경로를 따로 검증한다

| 경로 | 검증할 대상 | 성공 기준 — 제안 |
|---|---|---|
| 공개 웹 | 접근·색인·근거 본문·URL·지역 | 주요 사실을 읽고 정확한 모델로 연결 |
| 상품 피드 | 승인·Stable schema·식별자·변형·시장 | 제출/처리와 웹 정합성, 정보 갱신 |
| 앱·도구 | 사용자 연결·권한·지원 기능 | 요청한 과업에 필요한 범위만 읽거나 실행 |
| 거래 API | 가격/재고 확인·승인·주문 상태 | 판매 조건과 실행 권한, 실패 복구 |

[Plugins 문서](evidence/OAI-PLUGINS-20261006-001.md)의 연결·앱 자격은 크롤러 허용과 다르다. 피드의 country/currency 필드를 채운 것만으로 한국 시장이 활성화되지 않으며, checkout 플래그도 판매자 결제 온보딩을 대신하지 않는다.

## 점검 순서와 업무 산출물 — 제안

1. **URL 표본:** 대표 모델·설치·보증·반품 페이지를 선정하고 국가·URL·갱신 책임자를 기록한다.
2. **접근 비교:** 검색·학습·사용자 조회 목적별 정책과 CDN·robots·인증 조건을 대조한다.
3. **읽기 비교:** 필수 제품 사실을 원문·raw HTML·렌더링·피드에서 확인해 누락과 충돌을 기록한다.
4. **정합성 개선:** 같은 모델·옵션·가격·서비스 조건의 원천과 갱신 규칙을 맞춘다.
5. **결과 확인:** 접근 오류·필수 사실 누락·갱신 지연·오래된 답변을 관찰한다. 노출·추천 효과는 G-4에서 별도 측정한다.

| 운영 지표 | 정의 | 원인 판단에 필요한 기록 |
|---|---|---|
| 접근 성공률 | 성공 응답 수 / 같은 목적의 시도 수 | 봇·국가·상태 코드·시간 |
| 필수 정보 가독률 | 읽힌 필수 항목 / 사전 지정 항목 | 항목·전달 경로·추출 방식 |
| 웹/피드 일치율 | 일치 모델-필드 / 비교 모델-필드 | 모델·옵션·원천 시각 |
| 갱신 지연 | 원천 변경부터 대상 경로 반영까지 | 변경 시각·반영 시각·허용 지연 |
| 오래된 사실 비율 | outdated 항목 / 평가한 사실 | 질문·시점·모델·올바른 값 |

이는 테스트 설계다. LGE.com robots·CDN·페이지·로그를 실제 검사하거나 정책·파일을 배포한 결과가 아니다. llms.txt는 다른 서비스의 공식 지원·실제 이용 목적이 확인될 때만 별도 검토한다.
