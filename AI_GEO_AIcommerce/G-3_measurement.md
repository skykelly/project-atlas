# G-3. AI 유입·성과 측정·벤치마크

[목차](README.md) · [발견·탐색](G-1_ai_search_geo.md) · [Commerce](G-4_agentic_commerce.md)

> **핵심 결론:** AI 성과는 질문별 발견 품질, 플랫폼 노출·인용, 식별된 방문, 구매·고객 가치로 연결해 측정한다. 서로 다른 분모를 합산하지 않고 귀속 성과와 증분 효과를 분리해야 한다.

_조사 창: 2026-01-01~2026-10-06. 근거 확인일: 2026-10-06._
이 문서는 **측정 정의·도구·검증 설계**를 관리한다. 전체 시장 규모·연표는 [G-7](G-7_market_adoption.md), 광고 상품·과금 구조는 [G-5](G-5_ai_ads_monetization.md)에 둔다. 내부 AI referer MAU 실측값은 공개하지 않는다.

Google의 과거 Web 전체 보고 설명과 최신 전용 보고서를 날짜별로 구분한다. Search Console 속성/URL 집계 차이, preview 레이블 변화, 실제 계정 가용성은 보고서 판독의 조건이다. “AI를 전혀 측정할 수 없다”와 “한 도구로 AI 전체를 측정할 수 있다” 모두 피한다.

## 지표 사전 — 제안

| 층위·지표 | 계산·단위 | 반드시 고정할 조건 |
|---|---|---|
| 브랜드 언급률 | 브랜드 언급 답변 / 유효 평가 답변 | 질문 묶음·플랫폼·언어·반복 수 |
| 정확한 제품 추천률 | 대상 조건에 맞는 모델 추천 / 평가 답변 | 국가·판매 모델·필수 제약 |
| 근거 정합률 | 올바른 원문으로 지지되는 주장 / 평가 주장 | 사실 판정 기준·문서 버전 |
| 플랫폼 노출·인용 | 해당 도구가 정의한 건수·share | 플랫폼 분모·기간·시간대 |
| AI referral 세션 | 사전 규칙에 맞는 사람의 방문 세션 | referrer/UTM·중복·봇 제외 |
| AI referral MAU | 해당 월 식별된 AI 유입 사용자 | 사용자 식별 방식·월 기준·중복 제거 |
| 구매 CVR | 구매 세션 / 평가 세션 등 사전 정의 | 세션/사용자 분모·주문 상태·기간 |
| 유효 문의 CVR | 검증 문의 / 평가 세션 등 사전 정의 | 상담·데모·구매와 구분 |
| 귀속 CPA | 광고비 / 귀속 전환 | 모델·창·중복 이벤트·비용 범위 |
| 증분 고객 가치 | 대조 조건 대비 추가 마진·고객 가치 | 실험·불확실성·반품·장기 비용 |

자사 AI Chat 이용과 외부 AI referral는 다른 집단이다. 같은 고객이 두 경로에 있으면 집단별 지표를 유지한 뒤 합집합 분석에서만 중복 제거한다. 사용자 식별이 부족하면 세션을 MAU로 이름 바꾸지 않는다.

## 공개 benchmark의 구체적 조건

| 연구·관측 기간 | 수치 | 실제 분모·전환 | 적용 한계 |
|---|---|---|---|
| [Adobe](evidence/ADI-MARKET-20261006-001.md), 미국 retail 2026-03 | AI 구매 CVR 상대 +42% | non-AI 방문 구매율 대비 | 절대 CVR·개별 AI 표본·인과 실험 미공개 |
| 같은 연구, retail 2026-07 | 구매 CVR 상대 +60%, cart 추가율 +28% | 동월 non-AI 대비 각각 다른 행동 | 업종·의도·채널 구성이 다를 수 있음 |
| 같은 연구, travel 2026-07 | 구매 CVR 상대 −1% | non-AI 대비 | retail의 우위를 모든 업종으로 확장 불가 |
| [Opollo](evidence/OPO-BENCH-20261006-001.md), 2025-01~2026-01 | 평균 AI 14.2%·organic 2.8%; 중앙값 13.6%·2.5% | IT/기술 서비스 312개, qualified enquiries | 월 AI 세션 10 미만·CVR 35% 초과 제외, 구매 아님 |
| [독립 UI/API audit](evidence/RES-AUDIT-20261006-001.md), 09월 제출 | 표시 도메인 UI/API 겹침 ChatGPT 12.0%·Gemini 14.8% | 117개 제품 질문, 네덜란드 로그아웃 UI·API 반복 | 인용 관찰, 전환 연구·한국 대표 표본 아님 |
| [OpenAI partner 사례](evidence/OAI-ADS-20261006-001.md), 10-05 소개 | WeightWatchers 귀속 CPA −15.3% | blended paid search 대비 | 표본·기간·원자료 부족, 증분 CAC 아님 |

**계산 예시 — 가상 데이터:** non-AI CVR 2%, AI CVR 3.2%면 상대 +60%와 차이 +1.2%p다. AI 100세션과 non-AI 100,000세션처럼 표본이 다르면 비율만으로 우열을 확정하지 않는다. 분모·전환 수·불확실성을 함께 남긴다.

Opollo 결과는 유효 문의이며 구매와 별도로 비교한다. 2026년에 발표됐어도 2025 관측을 포함한다. 월별 상대 차이가 커졌다는 이유로 GEO 콘텐츠 변경이 효과를 냈다고 단정하지 않는다.

## 실제 소비자 화면과 API를 분리하는 이유

독립 연구는 같은 질문의 consumer UI와 API에서 표시되는 도메인이 크게 달랐다. 이는 API 관찰을 소비자 노출의 완전한 대리값으로 쓰기 어렵다는 근거다. 답변 텍스트·표시 인용·상품 카드·검색 도구 결과도 서로 다른 층이다.

| 관찰 조건 | 기록할 최소 항목 | 분석에서 구분할 것 |
|---|---|---|
| 실제 UI | 플랫폼·국가·언어·날짜·로그인·질문·답변 | 개인화·모델 미노출·상품/광고 카드 |
| API | 모델·설정·검색 도구·질문·응답 | UI와 다른 모델/도구 경로 |
| 반복 | 같은 조건의 회차·순서·간격 | 단일 답변·빈 응답·파싱 실패 |
| 근거 판정 | 제품 원문·버전·지원 주장 | 인용 존재와 주장 지지 여부 |

빈 응답·도구 실패·화면 추출 실패를 성공적인 추천의 분모에서 조용히 제외하지 않는다. 유효 답변 기준과 제외 수를 함께 보고한다.

## LGE.com 검증 설계 — 제안

| 순서 | 실험·집계 | 의사결정에 남길 결과 |
|---|---|---|
| 1 | 국가·제품군·설치/비교 질문과 성공 조건 정의 | baseline, 필요한 표본·기간 |
| 2 | 자연 AI·paid AI·자사 AI Chat·검색의 채널 규칙 정의 | 변경 이력·중복·미식별 범위 |
| 3 | 실제 UI 질문 평가와 사이트 이벤트 연결 | 발견 품질·landing 모델·구매 경로 |
| 4 | 정보/피드 개선, 상품·프로모션 변화를 표시 | 변경 항목·동일 조건 전후·비교군 |
| 5 | 구매·문의·신규·반품·마진 추적 | 귀속 효율·증분 추정·불확실성 |

가능한 실험은 질문/제품군별 정보 개선 전후와 비교군, 국가별 광고 증분 실험 등이다. 외부 답변은 플랫폼 자체 변경의 영향을 받으므로 완전한 무작위 통제가 가능한지 별도 판단한다. 실제 baseline 없이 기간·표본 수·유의성을 약속하지 않는다.

## 보고서를 오해하지 않는 판독 규칙

- Citation Share 상승 + 방문 정체: 인용 노출은 늘었지만 클릭·의도·계절이 달랐을 수 있다. 사이트 매출 하락으로 즉시 판단하지 않는다.
- AI CVR 상승 + 유입 감소: 높은 의도 고객만 남았을 수 있다. 매출·전환 수·객단가·신규·반품을 함께 확인한다.
- Direct 증가 + AI referral 정체: 미식별 가능성을 검토하되 Direct 전부를 AI로 재분류하지 않는다.
- 채널 규칙 변경 후 급증: 재집계 가능한지 확인하고 시계열 단절을 표시한다.
- attributed CPA 개선: 증분 효과·전체 비용·마진이 개선됐는지는 별도 확인한다.

[기존 Promodo 사례](../AI_SalesMarketing/cases/PMD-20261001-001.md)의 전후 관찰·증분 한계도 유지한다. 이번 문서는 공개 근거를 바탕으로 한 측정 설계이며 계정 접속·내부 집계·추적 코드 배포·한국어 UI 실험을 완료한 결과가 아니다.
