### 통합 판단과 문서의 역할

현재 운영 카테고리는 **G-1~G-6의 7개**다. Query fan-out은 고객 질문에 필요한 근거를 탐색하는 방식이므로 G-1의 발견·추천 콘텐츠 설계에 통합했다. 별도 탐색 카테고리와 이동 안내 파일은 삭제하고 전체 번호를 연속으로 정리했다.

| 역할 | 관리 문서 | 구체적인 산출물·통합/유지 이유 |
|---|---|---|
| 발견·추천의 정보 설계 | G-1 | 질문-근거 대응표·정확한 모델 추천·콘텐츠 개선·반복 관찰 |
| 기술 접근·정보 전달 | G-2 | 봇 목적별 정책·가독성·웹/피드 정합성·갱신 지연, 콘텐츠 설계와 책임이 다름 |
| 성과 판정·검증 | G-3 | 도구/분모·지표 사전·귀속/증분·UI/API 실험, 시장 현황과 평가 방법이 다름 |
| 실제 거래 실행 | G-4 | 자격·피드·견적·승인·주문·설치·복구, 플랫폼 전략과 운영 조건이 다름 |

## 2026년 시장 재조사 — 10월 6일 기준

2026-01-01~2026-10-06 공개 발표·연구·현행 문서를 다시 조사해 25개 근거 문서를 확보했고, 이후 중복을 통합해 **현재 7개 운영 카테고리**로 정리했다. 처음 읽을 때는 [시장 개관·수치·연표·첨부 검증](G-7_market_adoption.md) → [7개 플랫폼 전략 비교](G-6_platform_ecosystems.md) → 관심 카테고리 순서를 권장한다.

Google·OpenAI·Microsoft·Amazon·Perplexity·Anthropic·네이버를 비교했다. 시장 규모는 Similarweb 웹 추정, 쇼핑 행동은 Adobe 미국 관측, B2B 문의 전환은 Opollo 고객 연구로 구분했다. 발표일이 2026년이어도 관측이 2025년이면 명시하고, 10월 현재의 사건과 5~7월까지의 시장 데이터를 혼동하지 않는다.

OpenAI의 3월 상품 발견·판매자 checkout 중심 변경, ChatGPT 광고의 8월 한국 출시·9월 Sponsored Agents·10월 새 형식, Google의 검색·개인 맥락·UCP·광고·측정, Amazon의 통합 쇼핑, 국내 네이버 검색 연결을 추가했다. 한국 도입·내부 MAU·실제 계정/거래/캠페인 테스트는 수행하지 않았다. Meta·중국 commerce·9~10월 전체 시장 실적은 후속 조사 범위다.

## 출발점과 범위

2026-08-25 한국 시간의 ‘AI 변화 알림 설정’ 대화에서 정한 범위를 이어받았다. 매일 확인하고 관련 주요 업데이트를 폭넓게 선별하되, 반복 내용과 근거가 약한 전망을 제외한다. 변경 내용·영향·출처·긴급도와 권장 조치를 함께 기록한다.

2026-10-06에 공식 자료를 기반으로 근거 문서 10건과 다섯 카테고리의 1차 비교 종합을 작성했다. 날짜가 없는 운영 문서는 확인일 기준의 현황이며, 새로 발표된 사건으로 표현하지 않는다. 사이트·계정·한국어 화면 실험은 수행하지 않았다. 이 문서의 일일 확인은 운영 기준이며 저장소와 기존 알림의 연결·자동 실행을 확인했다는 뜻은 아니다.

## 중요한 변화의 판정

다음 중 하나가 바뀌고 대상 서비스에 구체적인 영향 경로가 있으면 조사 대상으로 남긴다.

1. **고객 행동:** 검색·비교·추천·구매가 이루어지는 화면이나 경로의 변화
2. **기업 접근:** 크롤링·인용·피드·API·거래 연결의 권한 또는 기술 조건 변화
3. **운영 조건:** 지원 국가·언어·판매자 자격·비용·정책·출시 단계 변화

중요도와 긴급도는 구분한다. 중요한 연구 결과라도 즉시 변경할 사항이 없으면 모니터링으로 남긴다.

## 기록 원칙

- Markdown이 지식의 기준이다. 카테고리에는 비교·해석을, 개별 변화의 사실과 출처는 필요할 때 만드는 단일 근거 문서에 기록한다.
- 실제 변경을 확인했을 때만 근거 문서를 추가한다. 출처 DB·별도 편집 JSON·빈 문서 폴더를 미리 만들지 않는다.
- 개별 기록에는 제목, 주 카테고리, 발표일, 실제 시행일, 원문 확인일, 출시 단계, 국가·언어·대상, 변경 내용, 영향, 긴급도, 권장 행동과 한계를 포함한다.
- 공식 발표와 실제 문서·제품 동작, 발표·베타·일반 제공을 구분한다. 도입 가능 여부가 미확인이면 미확인으로 남긴다.
- 측정치는 값·단위·기간·표본·비교 대상·출처를 함께 기록한다. AI referer MAU의 실제 내부 수치는 공개 조사 문서에 넣지 않는다.
- 사실 → 해석 → LGE.com 적용 가설을 구분한다. 즉시 조치·단기 실험·모니터링 KPI는 제안이며 실제 적용으로 쓰지 않는다.
- 기존 영업·마케팅 사례는 복제하지 않고 해당 Markdown을 연결한다. 코드·설정은 공통 scripts, 수집 원본·생성 결과는 data/AI_GEO_AIcommerce에 둔다.
