## 출발점과 범위

2026-08-25 한국 시간의 ‘AI 변화 알림 설정’ 대화에서 정한 범위를 이어받았다. 매일 확인하고 관련 주요 업데이트를 폭넓게 선별하되, 반복 내용과 근거가 약한 전망을 제외한다. 변경 내용·영향·출처·긴급도와 권장 조치를 함께 기록한다.

이번 단계는 카테고리와 조사 기준을 구성한 것이다. 개별 플랫폼의 최신 기능·지원 국가·상용화 여부를 검증한 시장 보고서는 아직 작성하지 않았다. 이 문서에 적힌 일일 확인은 조사 운영 기준이며, 저장소와 기존 알림의 연결·자동 실행 여부를 확인했다는 뜻은 아니다.

AI_IndustryTrend의 모델·기업·인프라 전반 조사는 다음 작업으로 남긴다. 이 주제에서는 해당 변화가 발견·추천·거래 흐름을 바꿀 때만 포함한다.

## 중요한 변화의 판정

다음 중 하나가 바뀌고 대상 서비스에 구체적인 영향 경로가 있으면 조사 대상으로 남긴다.

1. **고객 행동:** 검색·비교·추천·구매가 이루어지는 화면이나 경로의 변화
2. **기업 접근:** 크롤링·인용·피드·API·거래 연결의 권한 또는 기술 조건 변화
3. **운영 조건:** 지원 국가·언어·판매자 자격·비용·정책·출시 단계 변화
4. **성과 판단:** 측정 정의·식별 가능성·전환 귀속·벤치마크의 변화

중요도와 긴급도는 구분한다. 중요한 연구 결과라도 즉시 변경할 사항이 없으면 모니터링으로 남긴다.

| 긴급도 | 판정 기준 | 권장 처리 |
|---|---|---|
| 즉시 대응 | 운영 중 기능·정책·접근·측정에 영향을 주는 확정 변경 | 담당자가 영향 범위를 확인하고 조치 |
| 단기 실험 | 공식 출시나 문서 변경으로 검증 가능한 기회가 생김 | 조건을 확인해 제한된 실험 설계 |
| 모니터링 | 연구·파일럿·국가 제한 등으로 직접 적용이 아직 불명확 | 적용 조건과 후속 확인 시점 기록 |

## 기록 원칙

- Markdown이 지식의 기준이다. 카테고리에는 비교·해석을, 개별 변화의 사실과 출처는 필요할 때 만드는 단일 근거 문서에 기록한다.
- 실제 변경을 확인했을 때만 근거 문서를 추가한다. 출처 DB·별도 편집 JSON·빈 문서 폴더를 미리 만들지 않는다.
- 개별 기록에는 제목, 주 카테고리, 발표일, 실제 시행일, 원문 확인일, 출시 단계, 국가·언어·대상, 변경 내용, 영향, 긴급도, 권장 행동과 한계를 포함한다.
- 공식 발표와 실제 문서·제품 동작, 발표·베타·일반 제공을 구분한다. 도입 가능 여부가 미확인이면 미확인으로 남긴다.
- 측정치는 값·단위·기간·표본·비교 대상·출처를 함께 기록한다. AI referer MAU의 실제 내부 수치는 공개 조사 문서에 넣지 않는다.
- 사실 → 해석 → LGE.com 적용 가설을 구분한다. 즉시 조치·단기 실험·모니터링 KPI는 제안이며 실제 적용으로 쓰지 않는다.
- 기존 영업·마케팅 사례는 복제하지 않고 해당 Markdown을 연결한다. 코드·설정은 공통 scripts, 수집 원본·생성 결과는 data/AI_GEO_AIcommerce에 둔다.
