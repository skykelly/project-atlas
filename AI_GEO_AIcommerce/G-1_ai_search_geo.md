# G-1. AI Search·GEO·브랜드 발견·탐색 경로

[목차](README.md) · [기술 접근](G-3_crawlers_content_access.md) · [성과 측정](G-4_measurement.md)

> **핵심 결론:** GEO는 고객의 복합 질문에 필요한 제품 근거를 발견·비교·추천 과정에 제공하는 일이다. 웹 인용, 상품 후보, 외부 브랜드 상담을 구분하고, 질문별 페이지 증식보다 실제 판단에 필요한 정보의 누락을 해결해야 한다.

_조사 창: 2026-01-01~2026-10-06. 근거 확인일: 2026-10-06._
기존 G-2의 query fan-out·탐색·추천 경로를 이 문서에 통합했다. 플랫폼 전체 전략은 [G-7](G-7_platform_ecosystems.md), 시장 규모와 전체 연표는 [G-8](G-8_market_adoption.md)에서 관리한다.

## 2026년 발견·추천 방식의 구체적인 변화

| 시점·근거 | 확인된 변화 | 브랜드가 준비할 정보 | 제공·해석의 경계 |
|---|---|---|---|
| 03-24 [OpenAI 상품 발견](evidence/OAI-DISCOVERY-20261006-001.md) | 시각적 상품 탐색·나란히 비교, ACP를 발견 데이터로 확대 | 가격·변형·리뷰·제품 특성과 정확한 판매자 링크 | 피드 연동이 내장결제 승인은 아님 |
| 05-19 [Google Search](evidence/GOO-SEARCH-20261006-001.md) | 개인 연결·다중 입력·후속 질문·지속 과업으로 검색 확대 | 생활 맥락·호환·사용 조건·후속 행동의 근거 | 개인 연결은 선택 사항, 기능별 일정·계정 조건 구분 |
| 07-10 [Google 가이드](evidence/GOO-GEO-20261006-001.md) | RAG·관련 하위 검색 fan-out, 기존 검색 품질 체계 기반 | 고유 경험·시험·사양·설치·비교에 대한 직접 근거 | Google의 설명을 모든 AI 구조로 일반화하지 않음 |
| 07-15 [네이버 AI탭](evidence/NAV-AGENT-20261006-001.md) | 구매 데이터·리뷰·UGC를 활용한 전자제품 등 추천 | 국내 모델·판매 조건·사용 경험·지역 맥락 | 자체 발표, 추천 가중치·한국 전체 구매 효과 미공개 |
| 09-16 [Google 상품 속성](evidence/GOO-COMMERCE-20261006-001.md) | 대화형 속성의 추천 활용 사례 발표 | 용도·호환·대체품·질문에 답하는 상품 설명 | lululemon 50% 속성 반영은 CVR 50%가 아님 |
| 현행 [Business Agent](evidence/GOO-BRAND-20261006-001.md) | 웹·Merchant Center를 활용하는 Search 내 브랜드 상담 | 브랜드가 책임질 FAQ·제품 정책·고객 이관 | 미국 기반·검증 MC·승인 무료 listing 50개 이상 등 자격 |

**해석:** 발견 대응의 대상은 ‘AI 답변에서 이름이 나오는가’에서 ‘올바른 모델이 어떤 조건의 후보로 제시되는가’로 확장된다. 언급이 늘어도 잘못된 해외 모델·옵션·판매 조건이 함께 나오면 고객 과업을 해결하지 못한다.

## 네 가지 노출을 별도로 평가한다

| 노출 | 실제로 확인할 것 | 실패 예시 — 가상의 가전 질문 | 개선 산출물 |
|---|---|---|---|
| 브랜드 언급 | 브랜드가 답변에 등장 | 브랜드명만 나열, 조건 적합성 설명 없음 | 생활 과업별 브랜드/제품 강점의 검증 근거 |
| 출처 인용 | 어느 URL이 어떤 주장을 지지 | 소비전력 주장에 해당 조건 없는 페이지 인용 | 시험 조건·대상 모델·확인일이 있는 원문 |
| 제품 추천 | 정확한 모델·옵션이 후보에 포함 | 국내 판매 모델과 해외 모델 혼동 | 국가별 모델·변형·식별자 대응 |
| 상담·구매 이관 | 어디로 넘어가 무엇을 계속하는가 | 비교한 옵션과 다른 상품 페이지로 이동 | 옵션을 유지하는 링크·상담/구매 연결 |

자연 답변과 유료 노출은 분리한다. Sponsored Agents·Leads 광고의 접점·비용은 [G-6](G-6_ai_ads_monetization.md), 주문 가능성과 결제 책임은 [G-5](G-5_agentic_commerce.md)에서 다룬다.

## Query fan-out을 콘텐츠 준비에 적용하는 방법

[Google 공식 가이드](evidence/GOO-GEO-20261006-001.md)는 관련 질의를 병렬 생성해 추가 검색하는 구조를 설명한다. 아래 분해는 **기업이 지식 누락을 찾기 위한 설계 예시**이며 실제 서비스가 생성한 내부 질의 목록이 아니다.

**질문 예시:** “작은 아파트에서 밤에 쓰고, 이사 후에도 설치하기 쉬운 세탁기를 찾고 싶다.”

| 하위 판단 | 필요한 제품·서비스 근거 | 표현에 필요한 조건 | 빠졌을 때의 문제 |
|---|---|---|---|
| 설치 가능한가 | 외형·문 열림·필수 여유·급배수·전원 | 모델·치수 단위·설치 환경·예외 | 본체 크기만 비교해 설치 불가 추천 |
| 야간 사용에 맞는가 | 소음 시험·모드별 작동 특성 | 측정 방법·코스·부하·설치 조건 | 단일 dB값을 모든 코스의 성능으로 해석 |
| 이동·재설치가 가능한가 | 이전설치·서비스 지역·비용 확인 경로 | 국가·지역·서비스 정책의 유효일 | 무료/전국 가능처럼 과장 |
| 총비용은 얼마인가 | 판매 옵션·배송·설치·추가 서비스 | 가격 시점·조건·제외 비용 | 상품가와 실제 지불액의 차이 |
| 어떤 후보를 제외해야 하나 | 호환 불가·환경 제약·사용 제한 | 명시된 불가 조건·확인 필요 항목 | 좋은 특성만 설명하고 부적합 후보 유지 |

권장 문서 구성은 질문에 대한 짧은 답 → 적용 모델·조건 → 근거 → 예외 → 다음 확인 경로다. 이 구성은 운영 제안이며 플랫폼이 요구하는 특별 GEO 마크업이 아니다. 동일 내용으로 모든 질문 변형 페이지를 만드는 대신 제품 원문·설치 가이드·서비스 정책을 연결한다.

## 어떤 콘텐츠를 우선 보완할 것인가?

| 정보 유형 | 보완할 실질 내용 | 주의할 주장 |
|---|---|---|
| 공식 사양 | 국내 모델·변형·액세서리 호환·사용 제한 | 해외 사양·유사 모델 혼용 |
| 성능 시험 | 시험 주체·조건·비교 대상·측정값·날짜 | 조건 없는 “최고·1위” |
| 설치·사용 | 고객 공간·동선·전원·급배수·유지관리 | 본체 규격만으로 설치 보장 |
| 정책·총비용 | 배송·설치·이전·보증·반품·지역 예외 | 오래된 가격·무료 조건 |
| 외부 리뷰·UGC | 실제 사용 환경과 관찰, 공식 사실과 구분 | 경험담을 제품 전체의 확정 성능으로 승격 |
| 상품 피드 | 웹과 같은 모델·변형·가격·재고·링크 | 등록 성공을 정확한 추천의 증거로 사용 |

[Perplexity 현행 문서](evidence/PER-COMMERCE-20261006-001.md)는 깊은 상품 정보·리뷰·가격·재고를 추천에 활용한다고 설명한다. 플랫폼별 비공개 가중치는 알 수 없으므로 특정 콘텐츠 형식의 순위 보장을 약속하지 않는다.

## 반복 관찰을 통한 실행 패턴 — 제안

| 단계 | 실행할 일 | 남길 결과·판정 |
|---|---|---|
| 1. 질문 선정 | 설치·비교·교체·관리 과업에서 실제 질문 선정 | 질문·국가·언어·예상 필수 조건 |
| 2. 화면 baseline | 실제 UI의 답변·상품 카드·인용·링크를 반복 기록 | 날짜·로그인·개인화·추천 모델·오류 |
| 3. 근거 대조 | 답변 주장과 제품/정책 원문을 비교 | 잘못된 사실·조건 누락·출처 불일치 |
| 4. 정보 개선 | 누락 근거와 웹·피드 불일치를 수정 | 변경 URL·모델·버전·책임자 |
| 5. 전후 비교 | 같은 질문·조건·반복 수로 재관찰 | 제약 충족·인용·모델 정확도·이관 변화 |

[독립 audit](evidence/RES-AUDIT-20261006-001.md)은 117개 질문을 반복 관찰했으며 UI/API 표시 도메인 겹침이 ChatGPT 12.0%, Gemini 14.8%였다. API만으로 실제 소비자 화면을 대신하면 안 되는 근거다. 해당 표본·국가·모델에 한정된 결과이며 한국 기대 성과가 아니다. 지표 정의는 [G-4](G-4_measurement.md)에 둔다.

## 비교 종합과 우선순위

먼저 접근·색인 조건을 [G-3](G-3_crawlers_content_access.md)에서 확인하고, 제품 판단에 필요한 고유 근거와 국내 모델 정합성을 보완한다. 다음으로 질문별 오류·제약 누락·정확한 이관을 관찰한다. 외부 브랜드 상담은 해당 국가 자격이 확인된 경우 별도 pilot으로 검토한다.

LGE.com Brand Answer Engine은 외부 답변의 제품 근거를, AI Chat은 고객 조건 확인·상담 이관을 담당하는 연결을 제안한다. 실제 내부 구조·성과·도입 완료를 설명한 것은 아니다. 한국어 화면 실험·새 콘텐츠 배포·계정 제공 확인은 후속 작업으로 남긴다.
