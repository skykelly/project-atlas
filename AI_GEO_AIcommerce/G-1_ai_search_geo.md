# G-1. AI Search·GEO·브랜드 발견

[목차](README.md) · [다음: 탐색 경로](G-2_query_fanout.md) · [변경 이력](LOG.md)

> **핵심 결론**
> 브랜드 발견은 플랫폼별 접근 조건, 질문에 답할 수 있는 고유 근거, 정확한 상품 정보와 외부 상담 경험을 함께 설계하는 과제다.

_공식 자료 확인일: 2026-10-06_

## 검증 근거에서 도출한 인사이트

### 1. ‘GEO 기법’보다 발견의 전제조건부터 확인한다

[Google 가이드](evidence/GOO-GEO-20261006-001.md)는 검색 품질 체계와 기술 조건에 기반한 AI 발견을 설명한다. 따라서 내부 실행 순서는 접근·설정 확인 → 정보 정확성 → 고객 질문에 대한 근거 → 노출 관찰로 제안한다. 특정 형식만 적용하면 추천된다는 주장은 별도 실험이 필요하다.

### 2. 상품 발견과 브랜드 상담은 연결되지만 서로 다른 기능이다

[Business Agent](evidence/GOO-BRAND-20261006-001.md)는 외부 검색 화면에서 브랜드와 대화하는 경로다. 자사 웹사이트의 상담 AI와 별개의 화면이므로 공통 제품 근거와 각각의 답변·이관 책임을 설계해야 한다는 해석이다. 현행 미국 판매자 자격은 한국 도입 근거가 아니다.

### 3. 제품 페이지와 피드는 같은 사실을 전달해야 한다

[OpenAI 상품 피드](evidence/OAI-FEED-20261006-001.md)의 발견용 정보는 제품·변형·가격·재고를 별도 전달한다. 웹 문서와 피드가 다르면 고객이 답변에서 구매 화면으로 이동할 때 조건이 어긋날 수 있다는 가설이다. 플랫폼별 스키마 이전에 상품 사실의 원천과 갱신 책임을 정한다.

## 비교 종합

| 근거 | 확인한 범위 | LGE.com 적용 판단 |
|---|---|---|
| Google 검색 가이드 | 발견의 기술·콘텐츠 조건 | 자사 접근·근거 점검 우선 |
| Google Business Agent | 외부 브랜드 상담·미국 자격 | 한국 제공과 답변 책임을 추가 확인 |
| OpenAI 피드 | 승인된 상품 데이터 연동 | 공통 데이터 준비, 시장 자격은 별도 |

## 우선 실행안 — 적용 가설

1. 대표 생활·설치·비교 질문을 선정해 답변 근거가 있는 페이지와 연결한다.
2. 웹·피드·AI Chat의 가격·설치 조건·제품 변형 불일치를 점검한다.
3. 언급·인용·추천·실제 방문을 별도로 측정한다.

위 실행안은 내부 적용 전 가설이다. 검증 자료는 플랫폼 문서이며 특정 콘텐츠 변경의 증분 매출 효과를 입증하지 않는다.

## 2026년 시장 변화로 보완한 발견 전략

[Google의 검색·개인화 확대](evidence/GOO-SEARCH-20261006-001.md), [OpenAI의 상품 발견 집중](evidence/OAI-DISCOVERY-20261006-001.md), [네이버의 국내 검색·쇼핑 연결](evidence/NAV-AGENT-20261006-001.md)은 발견 화면과 데이터의 범위가 넓어진 근거다. 웹 페이지 인용만 측정하면 상품 카드·브랜드 상담·리뷰 기반 후보 선별을 놓칠 수 있다.

| 발견 경로 | 필요한 입력 — 적용 가설 | 관찰할 결과 |
|---|---|---|
| 근거형 검색 답변 | 공식 사양·실험 조건·비교 기준·보증 | 브랜드/모델 정확도·출처 연결 |
| 상품 카드·비교 | 식별자·변형·가격·재고·판매 국가 | 잘못된 옵션·품절·가격 지연 |
| 국내 리뷰·UGC 결합 | 동일 모델명·사용 맥락·지역 판매 정보 | 해외 모델 혼동·근거 편향 |
| 개인화·후속 질문 | 고객이 선택한 조건·기존 제품 호환 | 제약 충족·추천 변동·명확한 설명 |
| 브랜드 상담 | 검증된 FAQ·실행/지원 이관 | 상담 주체·정보 신선도·미해결 |

공식 정책을 준수하는 것과 추천 포함은 별개의 결과다. [독립 audit](evidence/RES-AUDIT-20261006-001.md)은 플랫폼·반복·UI/API별 차이를 보여 준다. 최종 추천 이유에 사용된 주장과 실제 제품 근거를 대조하고, 단일 prompt 순위를 고정 사실로 저장하지 않는다. [플랫폼별 참여](G-7_platform_ecosystems.md)와 [시장 기간·분모](G-8_market_adoption.md)를 함께 읽는다.

## 범위

AI 검색·답변·추천 서비스에서 브랜드와 제품이 발견되는 조건을 조사한다. 단순 언급·인용·추천·실제 유입을 구분하고, 답변의 출처 선택과 제품 정보의 표현 방식에 집중한다.

검색 플랫폼의 신규 화면·추천 기능·출처 표시·판매자 참여 정책과 공식 웹사이트 관리 지침을 포함한다. 순위 보장이나 근거가 약한 GEO 성공 주장은 채택하지 않는다.

## 핵심 연구 질문

- 브랜드 언급, 출처 인용, 제품 추천은 각각 어떤 조건에서 발생하는가?
- 자사 제품 정보와 외부 리뷰·전문가·판매자 정보는 어떤 역할을 하는가?
- 질문 의도·언어·국가·로그인·시점에 따라 답변이 얼마나 달라지는가?
- AI Chat의 직접 상담과 외부 AI에서의 브랜드 발견은 어떻게 연결되는가?
- 기존 검색 최적화와 AI 답변 대응 중 공통 과제와 별도 검증이 필요한 과제는 무엇인가?

## 비교·종합 기준

| 비교 항목 | 확인할 내용 |
|---|---|
| 서비스와 화면 | 검색 답변, 대화, 쇼핑 추천 등 실제 고객 경로 |
| 정보 입력 | 웹 문서, 구조화 정보, 제품 피드, 외부 근거 |
| 노출 형태 | 언급, 인용 링크, 비교 후보, 구매 연결 |
| 적용 조건 | 국가·언어·사용자·판매자 제한과 출시 단계 |
| 근거 수준 | 공식 문서, 재현 테스트, 관찰 비교, 공급사 주장 |

## LGE.com 적용 가설

Brand Answer Engine의 우선 과제는 질문별 추천 근거가 될 수 있는 정확한 제품 정보와 신뢰 신호를 관리하는 것이라는 가설을 둔다. 제품 사양·사용 맥락·제약·비교 근거의 변경이 인용과 추천에 어떤 영향을 주는지 검증한다.

실험은 질문 묶음과 실행 조건을 고정하고 반복 측정한다. 언급 또는 인용이 늘었다는 사실만으로 증분 고객·매출 효과를 확정하지 않는다.

## 측정과 한계

질문별 브랜드 언급률, 자사 출처 인용률, 추천 포함률, 사실 오류, AI 유입을 함께 본다. 질문 표본·반복 횟수·측정 환경을 공개하고 범용 시장 점유율로 일반화하지 않는다.
