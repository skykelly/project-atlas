# ACP checkout — AI 화면과 판매자 거래 책임의 분리

[주제 목차](../README.md)

## 확인한 사실

ACP 개발은 개방되어 있지만 ChatGPT Instant Checkout은 승인 파트너 대상으로 설명된다. 판매자는 상품 피드, checkout, 결제 흐름을 구현한다.

ChatGPT가 사용자 정보를 수집해 판매자의 checkout endpoint와 연결하고 화면에 상태를 표시한다. 주문 검증·배송 옵션·세금·위험 판단·승인·결제는 판매자 시스템이 담당한다. OpenAI는 merchant of record가 아니다. 위임 결제에는 최대 금액·만료 조건이 있다.

## 출처·시점·근거 위치

- [ACP Key concepts](https://developers.openai.com/commerce/guides/key-concepts)
- 근거 위치: 승인 파트너 안내 / Handling orders and checkout / Handling payments.
- 절대 발표·갱신일 미공개. 2026-10-06 원문 확인.

## 해석과 적용 가설

외부 AI에서 거래가 완료되더라도 기업의 주문·결제·사후관리 책임을 유지하는 설계가 필요하다. 가전에서는 설치 조건·배송 약속·반품 제약을 실행 전에 검증하고 실패 시 고객에게 선택을 돌려주는 흐름을 제안한다.

## 측정 조건·한계

공식 기술 설명이며 실제 판매 효과와 한국 제공 여부를 입증하지 않는다. 결제 정보 처리의 법적 적합성은 이 문서에서 판단하지 않는다. 실제 주문·결제 테스트는 수행하지 않았다.

## 권장 행동

모니터링·설계 검토: 승인·중복·금액·취소·이관의 계약과 로그 항목 정의. KPI: 거래 성공·실패·중복·취소, 조건 위반. [Commerce 종합](../G-5_agentic_commerce.md)
