# ChatGPT 앱·Plugins — 도구 연결·브랜드 UX·checkout의 다른 자격

[주제 목차](../README.md)

## 현행 확인
- [Connected apps](https://help.openai.com/en/articles/11487775-connected-apps-in-chatgpt): 외부 자료 검색·대화 내 UI·지원 작업 실행. 앱 가용성은 요금제·지역·역할·워크스페이스·모델·인터페이스에 따라 다르다. Plugins가 앱·skills 등을 묶을 수 있으며 설치는 제공자 권한·인증을 대체하지 않는다.
- [Plugins checkout 문서](https://developers.openai.com/plugins/build/monetization): 일반 권장 경로는 자사 도메인 외부 checkout. 현재 승인 범위는 physical goods, selected marketplace embedded payment sheet는 beta. 가격·결제·배송·이행은 판매자 책임.
- 근거 위치: Availability / permissions / FAQ와 Overview / Recommended Monetization Approach. 절대 게시·갱신일 미공개, 2026-10-06 확인.

## 한계·분리 원칙
상품 피드·웹 크롤링·광고·Plugins 앱 심사·내장 결제 파트너 승인은 서로 대체되지 않는다. 연결 문서의 존재는 특정 브랜드 앱이 배포됐거나 한국 checkout이 허용됐다는 증거가 아니다. 계정 연결·사용자 동의·리뷰 절차는 참여 경로별로 확인한다.

## 적용 가설
브랜드별 설치 조건 계산·호환 비교·상담 이관처럼 고유 작업이 있는 경우 대화 UI와 외부 checkout을 검토한다. 단순 사이트 복제보다 과업 완결성·데이터 최소화·실패 시 이관을 평가한다.
