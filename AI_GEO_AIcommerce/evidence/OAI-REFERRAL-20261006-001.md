# ChatGPT — 검색 유입의 UTM 식별과 측정 경계

[주제 목차](../README.md)

## 확인한 사실

OpenAI의 Publishers and Developers FAQ는 ChatGPT 검색 결과의 referral URL에 `utm_source=chatgpt.com`을 자동 포함한다고 설명한다. 분석 도구에서 이를 이용해 검색 결과에서 유입된 트래픽을 관찰할 수 있다.

## 출처·시점·근거 위치

- [Publishers and Developers FAQ](https://help.openai.com/en/articles/12627856-publishers-and-developers-faq)
- 근거 위치: Publisher FAQs의 웹사이트 검색 노출·유입 설명.
- 원문 갱신 표기는 상대 날짜다. 절대 발표일·시행일을 추정하지 않았다. 원문 확인 2026-10-06.

## 해석과 적용 가설

LGE.com은 referrer와 UTM을 함께 점검해 실제 AI 검색 방문의 채널 정의를 만들 수 있다는 가설을 둔다. 이미 분류한 방문에 UTM 경로를 더할 때 중복 집계하지 않는다.

## 측정 조건·한계

UTM은 방문의 출처 표식이며 월간 고유 사용자를 자동 계산하는 것은 아니다. 모든 AI 사용·앱·공유 링크·외부 결제의 식별을 보장하지 않는다. 클릭하지 않은 추천은 포함하지 못한다. 직접 방문으로 돌아온 사용자와 증분 전환은 별도 검증이 필요하다.

## 권장 행동

단기 실험: 공개 검색 결과에서 실제 클릭한 랜딩 URL과 분석 수집값을 대조. KPI: UTM 유지율, 중복 제거, 신규 사용자·세션·전환 정의. 내부 MAU의 실제 값은 기록하지 않는다. [측정 종합](../G-4_measurement.md)
