# OpenAI 상품 피드 — Stable·시장·결제 자격 분리

[주제 목차](../README.md)

## 확인한 사실

현행 시작 문서는 상품 피드 온보딩을 승인된 파트너 대상으로 안내한다. 전체 파일과 API 갱신을 조합하는 경로가 있다.

파일 업로드 명세에서 Stable은 지원 경로이고 Draft는 계획·피드백용이다. 표준 업로드의 기본 시장은 미국이며 행의 국가·통화값만으로 다른 시장이 활성화되지 않는다. 추가 시장은 연동별 확인이 필요하다. 상품 발견, 광고, checkout은 별도 조건이고 checkout 플래그만으로 결제 온보딩이 완료되지 않는다.

## 출처·시점·근거 위치

- [Get Started](https://developers.openai.com/commerce/guides/get-started): 승인 파트너·Integration path.
- [Products Stable](https://developers.openai.com/commerce/specs/file-upload/products): Schema view / Geo tagging / Checkout.
- 절대 게시·갱신일 미공개. 2026-10-06 문서 상태이며 기능 최초 출시일로 해석하지 않는다.

## 해석과 적용 가설

LGE.com의 상품 식별자·변형·가격·재고·배송·반품 정보를 같은 정의로 관리하는 것이 연동 준비의 공통 기반이라는 가설을 둔다. 피드 준비와 한국 서비스 도입 판단은 별도 승인 조건이다.

## 측정 조건·한계

문서 열람만으로 LGE.com의 파트너 자격·한국 판매·KRW 결제 가능성을 확인할 수 없다. 국가 코드 필드가 존재한다는 사실은 한국 지원 증거가 아니다. 실제 피드를 제출하거나 거래를 시험하지 않았다.

## 권장 행동

단기 실험: 내부 SKU 소량 표본의 필드·신선도·변형 정합성을 검토. 한국 상용화는 지원 시장과 승인 확인 후 판단. [Commerce 종합](../G-4_agentic_commerce.md)

## 공개 판매자 신청 안내 추가 확인 — 2026-10-06

[판매자 페이지](https://chatgpt.com/merchants/)의 Apply to share your product feed / FAQ를 확인했다. 현재 shopping 제공은 미국 사용자로 안내하고 추가 지역·self-service portal은 향후 계획이다. 일반 판매자는 신청·대기 경로이며 Shopify·Etsy catalog는 이미 연결돼 별도 신청이 불필요하다고 설명한다. 대부분의 판매자는 피드로 시작하고 앱은 선택 사항이다. 이 페이지의 국가 범위는 해당 상품 shopping 경험에 관한 안내이며 한국에서 일반 ChatGPT 검색·대화 자체가 불가능하다는 뜻이 아니다.
