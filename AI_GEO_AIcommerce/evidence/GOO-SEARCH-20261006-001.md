# Google — 검색·개인화·지속 에이전트로 넓어지는 고객 접점

[주제 목차](../README.md)

## 사실과 시점
- [05-19 Search I/O](https://blog.google/products-and-platforms/products/search/search-io-2026/): AI Mode 월 이용자 10억 초과, 출시 이후 질의가 분기마다 2배 이상 증가했다고 발표. Gemini 3.5 Flash를 AI Mode 기본 모델로 세계 확대. 신규 검색창은 AI Mode 제공 국가·언어에서 점진 제공.
- 같은 발표: Personal Intelligence를 거의 200개 국가·지역, 98개 언어로 확대, 구독 불필요. Gmail·Photos는 선택 연결이며 Calendar는 당시 ‘soon’. 모든 계정에 모든 연결이 같은 날 제공됐다는 의미가 아니다.
- Search agents는 지속 모니터링·예약 후보 탐색·업체 전화 흐름을 발표했지만 기능별 대상과 향후 일정이 달랐다. generative UI·mini apps 역시 출시 예고를 포함한다.
- [06월 투자자 발표](https://blog.google/alphabet/investor-presentation-june-2026/): AI Overviews 월 이용자 25억 초과, Gemini app 월 이용자 9억 초과. Spark의 Google 도구 연결과 후속 MCP 연결 방향.
- [07-22 Q2 CEO 발언](https://blog.google/company-news/inside-google/message-ceo/alphabet-earnings-q2-2026/): Gemini app MAU 9.5억, Spark 미국·해외 이용 가능이라고 설명. AI 검색 기능에서 매주 수십억 웹 클릭을 보낸다고 주장하며 Search and Other 매출 YoY +17% 보고.

## 출처 위치·측정 한계
Search I/O: 서두 / Powerful AI / Search agents / Personal Intelligence. 투자자 발표: Unmatched global product footprint. Q2: Search / Gemini app.
숫자는 Google 자체 발표이며 플랫폼 간 중복 이용자, 측정 방법·국가별 분포·Spark 세부 자격은 미공개. AI Mode·AIO·Gemini 이용자를 합산하지 않는다. ‘해외 제공’은 한국의 특정 기능·계정 자격을 입증하지 않는다. Search 매출 성장을 AI의 인과 기여로 환산하지 않는다.

## 해석·적용 가설
검색창·개인 맥락·앱·구매가 연결되므로 정적인 키워드 점검에서 고객 제약·후속 질문·재방문 과업 점검으로 확장한다. 모델명은 발표일 기준이며 현행 모든 화면의 기본 모델이라고 유지하지 않는다.
