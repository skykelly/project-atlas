# OpenAI — 검색·학습·사용자 조회의 접근 정책 분리

[주제 목차](../README.md)

## 확인한 사실

| 식별자 | 공식 역할 |
|---|---|
| OAI-SearchBot | ChatGPT 검색의 콘텐츠 발견 |
| GPTBot | 기반 모델 학습에 사용할 수 있는 수집 |
| ChatGPT-User | 사용자 요청에 따른 페이지 방문 |

검색과 학습의 robots 설정은 독립적이다. 검색 봇을 허용하면서 학습 봇을 차단할 수 있다. ChatGPT-User는 자동 크롤러가 아니며 사용자 요청에는 robots 규칙이 적용되지 않을 수 있다. 공식 IP 목록이 제공된다. 검색 차단 시에도 탐색용 링크가 나타날 수 있다.

## 출처·시점·근거 위치

- [Overview of OpenAI Crawlers](https://developers.openai.com/api/docs/bots)
- 근거 위치: 서두의 독립 설정 설명과 User agent 표.
- 최초 발표일·절대 갱신일 미공개. 확인일은 2026-10-06이며 시행일로 대체하지 않는다.

## 해석과 적용 가설

기업의 ‘AI 봇 허용’은 단일 정책보다 목적별 선택으로 설계해야 한다. LGE.com의 CDN·robots·IP 검증 규칙을 검색·학습·사용자 조회별로 검토하는 실험을 제안한다.

## 측정 조건·한계

robots는 인증이나 민감정보 접근통제를 대체하지 않는다. 문자열만으로 봇의 신원을 확정하지 않는다. 허용은 검색 노출 보장이 아니다. 현재 사이트의 설정을 실제 변경하거나 테스트하지 않았다.

## 권장 행동

단기 실험: 공개 제품 URL 표본의 접근 성공·차단 원인·봇 목적을 비교. KPI: 목적별 접근 오류·정보 갱신 지연. [접근 종합](../G-2_crawlers_content_access.md)

## 광고 검증과 반영 시간 재확인 — 2026-10-06

같은 공식 bots 문서의 OAI-AdsBot 행에서 제출된 광고 landing의 정책·관련성 검증을 확인했다. 제출 광고 페이지만 방문하며 수집 내용을 기반 모델 학습에 쓰지 않는다고 설명한다. 검색·학습·사용자 조회와 별도 목적이다. 검색 robots 변경 후 약 24시간 안내는 시스템 정책 반영에 관한 값이며 답변 갱신·추천 노출을 보장하지 않는다. 공식 IP 대조 경로도 재확인했다.
