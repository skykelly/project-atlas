# 독립 연구 — 소비자 UI와 API의 추천·인용 차이

[주제 목차](../README.md)

## 원문·방법
[arXiv v1 HTML](https://arxiv.org/html/2609.18729v1), 2026-09-16 제출 preprint. Abstract / Data and Methodology / Limitations를 확인했다. 실사용 질의에서 상업 조언 corpus 2,528개를 구축한 뒤 117개 제품추천 질문을 consumer UI·API·AIO에서 반복 관찰했다. 1,755개 관찰과 제품추천 분석에 사용한 1,536개 답변은 다른 분모다.

## 확인한 수치
UI와 API의 표시 도메인 평균 겹침은 ChatGPT 12.0%, Gemini 14.8%. 서로 다른 consumer UI(ChatGPT/Gemini)는 평균 5.4%이며 비교의 76.7%는 공통 도메인이 없었다. API 기반 모니터링을 실제 소비자 화면의 대리값으로 단정할 수 없다는 근거다.

## 조건·한계
네덜란드 IP·로그아웃 consumer UI, 117개 질문을 3회씩 관찰한 audit이며 전체 한국어 이용자·현행 모델·매출을 대표하지 않는다. AIO는 2026-09-04~05 수집 351회 중 134회만 추출 가능한 실질 답변으로 분석했다. API는 gpt-5.6-luna와 gemini-3.5-flash-lite; UI와 모델 동일성을 확정하지 않는다. 구매율 연구가 아니며 광고 때문에 추천이 달라졌다는 인과 실험도 아니다. 동료 심사 여부·독립 재현은 확인하지 않았다.

## 적용 가설
한국어 고객 질문을 실제 UI와 API로 각각 반복하고 날짜·모델·로그인·국가·인용 층위를 기록한다. 단일 답변의 추천 순위를 고정 시장 점유율처럼 보고하지 않는다.
