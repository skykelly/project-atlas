# Google·Anthropic·Perplexity — 목적별 접근과 제품 통제의 차이

[목차](../README.md) · [콘텐츠 접근](../G-2_crawlers_content_access.md)

## Google: Search 통제와 다른 제품 이용 범위

- [Common crawlers](https://developers.google.com/crawling/docs/crawlers-fetchers/google-common-crawlers), Googlebot / Google-Extended. 마지막 갱신 2026-07-14 UTC, 확인 10-06. Googlebot은 Search 등을 수집한다. Google-Extended는 독립 HTTP user-agent 없이 robots 통제 token으로 Gemini Apps·Vertex의 미래 모델 학습·grounding 이용을 관리하며 Search 포함·순위에는 영향이 없다고 설명한다.
- [Search generative AI control](https://support.google.com/webmasters/answer/16908024), Change your control / inheritance. 08-31 세계 확대 안내, 확인 10-06. AIO·AI Mode·Discover의 적용 기능에 사이트 링크·내용을 포함/제외하고 부모·자식 속성 상속·override를 지원한다. 일반 Search 포함/순위·Ads/MC 참여·학습 통제와 별도다. 반영에는 캐시·전파 시간이 있을 수 있다.
- 두 문서의 학습·grounding 설명은 명시한 제품 범위를 그대로 구분한다. Search control 도움말의 Google-Extended 연결만으로 모든 Google 제품을 같은 정책으로 설명하지 않는다.

## Anthropic: 세 목적의 봇과 robots 준수

[공식 도움말](https://support.claude.com/en/articles/8896518-does-anthropic-crawl-data-from-the-web-and-how-can-site-owners-block-the-crawler), Bot 표 / opt out. 2026-04-07 표시, 확인 10-06. 최초 게시·갱신 구분은 미공개다.

ClaudeBot은 잠재 학습, Claude-SearchBot은 검색, Claude-User는 사용자 요청 조회다. bots는 robots의 do-not-crawl 신호와 CAPTCHA를 존중한다고 설명한다. 서브도메인별 정책·공식 IP 신원 확인 경로를 안내한다. 사용자 조회가 robots를 무시한다는 타 플랫폼 설명을 복사하지 않는다.

## Perplexity: 검색과 사용자 조회·WAF

[공식 Crawlers 문서](https://docs.perplexity.ai/docs/resources/perplexity-crawlers), User Agent / WAF / IP sources. 절대 게시·갱신일 미공개, 확인 10-06. 구 URL은 이 문서로 redirect됐다.

PerplexityBot은 검색 발견·링크, Perplexity-User는 사용자 요청 조회다. 둘 모두 기반 모델 학습 수집용이 아니라고 설명하며 사용자 fetch는 일반적으로 robots를 무시한다고 명시한다. WAF는 user-agent와 최신 공식 IP를 함께 대조하도록 안내한다. 정책 반영의 최대 24시간 안내는 노출·추천 갱신 시간 보장이 아니다.

## 해석·검증 한계

[OpenAI 목적별 봇](OAI-CRAWL-20261006-001.md)과 비교해 목적·플랫폼별 정책을 설계한다. 공개 정책 확인이며 실제 준수·LGE.com 설정·개별 요청을 독립 검증한 결과가 아니다. robots·검색 제외는 비공개 데이터의 인증·권한을 대체하지 않는다. 설정·WAF·계정 변경은 수행하지 않았다.
