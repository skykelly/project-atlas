# G-5. Agentic Commerce·Zero-click Shopping

[목차](README.md) · [이전: 성과 측정](G-4_measurement.md) · [변경 이력](LOG.md)

## 범위

AI가 탐색·비교·추천·장바구니·주문·결제·사후관리를 돕거나 실행하는 거래 흐름의 변화를 조사한다. 서비스가 에이전트라고 부르는지보다 실제로 수행하는 단계와 권한을 확인한다.

Zero-click은 자사 사이트 방문 없이 답변·추천이 완료되는 경우와 외부 화면에서 거래까지 완료되는 경우를 구분한다. 두 흐름을 하나의 지표로 묶지 않는다.

## 핵심 연구 질문

- AI는 정보를 추천하는가, 거래를 준비하는가, 실제 구매까지 실행하는가?
- 사용자 동의·권한·승인·금액 한도·취소·복구는 어떻게 설계되는가?
- 가격·재고·배송·반품·보증 정보를 어떤 주체가 책임지는가?
- 판매자 참여 자격, 국가·언어, 제품군과 결제 수단의 제한은 무엇인가?
- 거래 수수료·광고·추천 순위·고객 데이터 접근은 어떻게 달라지는가?

## 실행 단계별 비교

| 단계 | 확인할 실제 기능 | 주요 조건·보호 지표 |
|---|---|---|
| 탐색·추천 | 후보 검색·비교·적합성 설명 | 사실 오류·편향·후보 누락 |
| 거래 준비 | 재고·가격 조회·장바구니 | 정보 신선도·옵션·설치 조건 |
| 주문·결제 | 사용자 승인·거래 생성 | 권한·인증·중복 주문·금액 한도 |
| 사후관리 | 배송 조회·취소·반품 | 책임·복구·정책·고객 이관 |

## LGE.com 적용 가설

가전 거래에서는 제품 추천 이후 설치·배송·기존 제품 처리·보증 등의 조건 확인이 중요하다는 가설을 둔다. 에이전트 친화적인 상품 정보와 거래 인터페이스를 검토하되, 원문 검증 전 특정 프로토콜·플랫폼 지원을 도입 결정으로 연결하지 않는다.

Brand Answer Engine은 외부 추천의 근거를, AI Chat은 자사 상담·조건 확인과 실행 경로를 담당하는 연결을 검토한다. 외부 플랫폼에서 구매가 끝나는 경우 고객 관계와 사후관리 접점에 어떤 변화가 생기는지 별도로 평가한다.

## 측정과 한계

추천 채택률, 거래 준비·승인·완료율, 실패·중복·취소율, 설치 조건 오류, 고객 이관과 마진을 함께 본다. 외부 플랫폼에서 자사 사이트 클릭이 줄어도 전체 수요 감소로 단정하지 않으며, 매출 증가도 에이전트의 증분 기여로 바로 해석하지 않는다.
