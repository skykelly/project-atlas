# 2-2. AI를 활용한 영업 운영비 절감

[← 마케팅 운영비](2-1_marketing_cost.md) · [위키 목차](README.md) · [다음: CS·케어 비용 →](2-3_customer_care_cost.md) · [변경 이력](LOG.md)

> **핵심 결론**
> 영업 생산성의 핵심은 문서 초안을 빨리 쓰는 것이 아니라 **CRM·ERP·고객 활동 데이터를 영업의 일·주·분기 리듬에 연결해 준비·조회·기록을 자동 실행하고, 사람이 고객 판단과 관계에 집중하게 만드는 것**이다.

_근거 확인일: 2026-10-06_

## 핵심 인사이트

### 1. 영업의 반복 리듬을 예약 실행 가능한 워크플로로 만든다

[Anthropic](cases/ANT-20261001-001.md)의 영업 책임자는 고객 미팅 준비, 금요일 예측 보고, 분기 계정 우선순위라는 세 가지 주기를 자동화했다. Salesforce·BigQuery·일정과 내부 문서에서 데이터를 가져와 정해진 형식으로 결과를 준비한다. 본인 자기 보고로 일상 업무에서 **약 90분/일**, 별도의 주간 예측 보고에서 **약 3시간/주**를 절약했다. 두 시간 수치는 중복 가능성이 있어 합산하지 않는다.

### 2. 데이터 접근 병목을 대화형 조회로 제거한다

[비공개 의료기기 유통사](cases/VMD-20261001-001.md)는 Copilot Studio Agent를 Teams와 Dynamics 365 ERP에 연결했다. ERP 라이선스가 없는 영업사원도 주문·재고·배송·송장 정보를 직접 조회한다. 수행사 사례는 300~400명의 영업·CS 사용자가 매일 이용하고 요청당 **2~5분 절약**한다고 고객 추정치를 제시한다. 고객 실명, 총 기간, 실제 비용 감소액은 공개되지 않았다.

### 3. 계정 조사는 점수보다 근거와 사람의 조정 과정이 중요하다

Anthropic 책임자는 4,000개 계정을 웹·Salesforce·BigQuery 데이터로 하룻밤에 평가하고 각 차원의 근거와 대시보드를 만들었다. 먼저 소규모 영역을 시험하고 가중치를 조정한 뒤 전체에 적용했다. 계정 점수는 사실이 아니라 우선순위 제안이므로 영업 담당자가 근거를 보고 수정할 수 있어야 한다.

### 4. 시간 절약 추정과 실제 비용 절감을 구분한다

[Lumen Technologies](cases/LMN-002.md)는 판매자당 평균 **주 4시간** 절약과 연 **5,000만 달러 상당**의 효율을 회사 추정으로 제시한다. 이 금액은 예산 감소로 실현된 현금 절감이 아니라 절약 시간을 가치로 환산한 생산성 추정이다. 효과는 `시간 절약 → 고객 접촉 증가 → 파이프라인 품질 또는 운영비 변화`로 단계별 측정해야 한다.

### 5. 속도보다 데이터 완결성과 권한을 보호 지표로 둔다

자동화가 오래된 CRM 상태나 잘못된 재고를 빠르게 전달하면 피해가 커진다. 최신성, 출처, 사용자 권한, 기록 완결성, 사람 이관을 운영 조건으로 둔다. 계정·개인 데이터의 사용 범위와 외부 발송 승인도 분리한다.

## 글로벌 Best Practice의 공통 운영 모델

| 단계 | 영업 리듬 | AI·시스템의 역할 | 사람의 역할 |
|---|---|---|---|
| 준비 | 미팅 전 | CRM·사용·이력 통합 브리핑 | 맥락·관계 판단 |
| 조회 | 상담 중 | ERP·제품·가격·정책 검색 | 답변 확인·예외 처리 |
| 기록 | 미팅 후 | 요약·CRM 필드·다음 행동 초안 | 확정·수정·발송 승인 |
| 관리 | 주간 | 예측·변화·리스크 집계 | 원인 설명·자원 배분 |
| 계획 | 분기 | 계정 조사·우선순위 근거 생성 | 기준·가중치·공정성 조정 |

## 실무 적용 질문

- 미팅 전·중·후와 주간·분기 업무 중 어디에 반복 병목이 있는가?
- CRM·ERP·제품·가격 정보가 같은 권한과 최신성 기준으로 연결되는가?
- AI가 제안할 행동과 사람이 반드시 승인할 행동은 무엇인가?
- 절약 시간이 고객 접촉·기록 완결성·파이프라인 품질로 전환되는가?
- 생산성 환산액과 실제 운영비 감소를 별도로 보고하는가?
