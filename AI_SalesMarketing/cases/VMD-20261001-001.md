# 비공개 의료기기 유통사 / Velosio — ERP 조회 Agent — 영업·CS의 데이터 검색 부담 절감

[위키 목차](../README.md) · [2-2 영업 운영비 절감](../2-2_sales_cost.md)

> **큐레이션 상태: 채택.** 2026-10-06 수행사 원문에서 연결 구조와 수치를 확인했다. 익명 고객의 추정치를 독립 검증으로 해석하지 않는다.

## 요약

Teams에서 주문·재고·송장 정보를 조회, 요청당 약 2~5분 절약 추정

## 적용 내용

2026년 7월 7일 Velosio 사례에서 의료기기 유통사는 Copilot Studio Agent를 Teams에 배치해 Dynamics 365의 주문·재고·배송·송장 데이터를 조회한다. ERP 라이선스가 없는 영업 직원이 CS에 조회를 부탁하던 부담도 줄였다. 고객 추정으로 요청당 2~5분을 절약하며 영업과 CS 사용자 300~400명이 매일 활용하고 월 수천 건 상호작용을 처리한다. 고객 실명은 비공개이며 수치는 요청 종류에 따라 달라진다. 팀 전체 연간 시간·비용 절감액으로 환산하지 않았다. 사람의 답변·업무를 보조하는 도구 연결 Agent로 분류했다.

## 성과와 측정 조건
