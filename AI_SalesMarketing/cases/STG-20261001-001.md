# Stagwell / Assembly — MCP 연결 광고 감사 Agent — 수시간 작업을 수분으로

[위키 목차](../README.md) · [2-1 마케팅 운영비 절감](../2-1_marketing_cost.md)

> **큐레이션 상태: 채택.** 2026-10-06 원문과 주요 주장을 대조했다. 공급사 사례 확인은 독립적 비용 검증을 뜻하지 않는다.

## 요약

광고 데이터·전문가 감사 기준을 Copilot Agent에 연결해 반복 분석 시간을 단축

## 적용 내용

2026년 6월 22일 Microsoft Advertising 고객 사례에서 Stagwell의 Assembly는 M365 Copilot Agent를 Advertising MCP와 Azure AI Foundry에 연결했다. Agent가 실시간 캠페인 데이터를 가져와 사람이 만든 감사 기준을 적용하고 고객용 산출물을 작성한다. 실무자는 결과를 검토하고 실행을 결정한다. 공급사는 감사 소요가 수시간에서 수분으로 줄고 더 많은 시장·계정을 점검하게 됐다고 설명한다. 정확한 시간·표본과 금전 비용 절감액은 공개되지 않아 임의의 절감률은 계산하지 않았다. 마케팅 운영의 반복 분석 부담 절감을 이유로 2-1에 분류했다.
