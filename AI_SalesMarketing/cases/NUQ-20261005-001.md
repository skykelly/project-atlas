# Nubank — CS Agent 배포 전 시뮬레이션

[위키 목차](../README.md) · [2-5 리스크·품질 비용](../2-5_risk_quality.md)

> 원문을 확인해 채택한 사례다. 저자 프리프린트로 동료평가 전이며 서로 다른 A/B 결과를 합산하지 않는다.

## 요약

실제 A/B로 시뮬레이션 기반 개선 확인.

## 적용 내용

Nubank는 카드 업무 Agent를 가상 고객·도구로 검증한 뒤 배포했다. 카드 관리/배송 Agent A/B에서 tNPS +36.69점, 셀프서비스율 +4.90%p를 보고했다. 별도 모델 교체 A/B의 셀프서비스율 +8.82%p와 합산하지 않는다. 프리프린트이며 실험 날짜·금액 효과는 미공개다.

## 성과와 측정 조건

Seed 대표 지표: **+36.69점 — 거래 후 tNPS — Agent 비교 A/B**

첫 A/B의 Agent 개선과 후속 A/B의 모델 선택은 별도 실험이다. 36.69점과 8.82%p를 한 실험 결과처럼 묶지 않는다.

| 값 | 지표 | 원본 방향 표시 |
| --- | --- | --- |
| +36.69점 | tNPS — Agent 비교 | pos |
| +4.90%p | 셀프서비스율 — Agent 비교 | pos |
| +8.82%p | 셀프서비스율 — 별도 모델 비교 | pos |
