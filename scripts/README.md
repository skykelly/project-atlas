# 수집·정리 코드

코드와 필요한 설정을 이 폴더에 파일 단위로 추가한다. 역할별 하위 폴더는 만들지 않는다. 현재 크롤러·예약·JSON/HTML 출력 구현은 없다.

기준 입력은 각 주제의 Markdown이다. data/주제/seed는 최초 이관 자료로만 사용한다. 새 수집 자료·출력물은 data/주제 아래에 필요할 때 저장한다.

코드가 문서를 갱신할 때는 사례 → 카테고리 → LOG.md의 연결을 유지한다. 카테고리의 연구자 해석을 통째로 덮어쓰거나 seed에서 일괄 재생성하지 않는다. 경로는 이 파일의 상위 atlas 폴더를 기준으로 계산한다.
